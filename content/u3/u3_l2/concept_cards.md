# 元组——封了保鲜膜的购物车

## 📦 元组就是封了保鲜膜的购物车

上节课的列表像购物车，能随便加东西、拿东西。**元组（tuple）**也像购物车，但它**封了一层保鲜膜**——里面的东西定好了就不能再改、再加、再删了。

创建元组用**圆括号 `()`**，取元素、切片、`len()` 这些和列表**完全一样**：

```python
t = ("苹果", "香蕉", "橘子")    # 用圆括号 () 创建
print(t)                        # ('苹果', '香蕉', '橘子')
print(t[0])                     # 苹果，照样能按下标取
print(t[-1])                    # 橘子，负数下标也能用
print(len(t))                   # 3
```

## 🔒 不可变：元组的"紧箍咒"

元组最核心的特点就三个字：**不可变**。下面这些操作**全部会报错**：

```python
t = (1, 2, 3)
t[0] = 100      # ❌ TypeError: 'tuple' object does not support item assignment
t.append(4)     # ❌ 没有 append 这个方法
t.remove(1)     # ❌ 也没有 remove
```

> ⚠️ 这就是元组和列表最大的分水岭：**列表能增删改，元组一动就报错**。那元组能干嘛？能查！`count()`、`index()`、`in`、切片、遍历全都行。**什么时候用元组？一句话：数据定下来就不会变的时候**——比如坐标、RGB 颜色、游戏怪物的出生点。元组就是给数据上把锁，防止手滑。

## 🎁 解包：一口气把值分给多个变量

元组有个超帅的用法——**解包（unpacking）**：把元组的元素一口气分给多个变量：

```python
t = ("小明", 18, "高三")
name, age, grade = t      # 左边几个变量和右边元组元素一一对应
print(name)     # 小明
print(age)      # 18

a = 1
b = 2
a, b = b, a     # 一行交换两个变量的值！右边先打包成 (2, 1) 再解包给左边
print(a)        # 2
print(b)        # 1
```

> ⚠️ 解包时**变量个数必须和元素个数一致**：`a, b = (1, 2, 3)` 会报 `ValueError`！

## 🕳️ 单元素元组与互转：两个经典的坑

想创建一个只有一个元素的元组？直接写 `(5)` 是不行的——`(5)` 里的括号被 Python 当成"数学里的括号"，`(5)` 就是整数 5。**要加一个逗号**：

```python
t = (5)
print(type(t))     # <class 'int'>    糟了，这是个整数！
t = (5,)
print(type(t))     # <class 'tuple'>  这才是元组！

a = [1, 2, 3]
t = tuple(a)       # 列表 → 元组：(1, 2, 3)
b = list(t)        # 元组 → 列表：[1, 2, 3]
b.append(4)        # 变成列表就能改了
print(b)           # [1, 2, 3, 4]
```

> ⚠️ 记牢：**单个元素 + 逗号**才是一个元素的元组。`(5,)` 是元组，`(5)` 是整数。想把元组里的数据改一改？套路是：**先转列表改，再转回元组**。
