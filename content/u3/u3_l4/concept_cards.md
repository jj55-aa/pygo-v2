# 集合——装"不重样"宝贝的袋子

## 🎒 集合就是自动去重的袋子

想象你有一个神奇的袋子，往里扔东西会自动去重——你扔进两颗一样的糖，袋子里只会有一颗。**集合（set）**就是这样的袋子：**里面的元素不重复**，而且**没有顺序**。

创建集合用**花括号 `{}`**，元素用逗号隔开：

```python
s = {1, 2, 2, 3, 3, 3}    # 明明写了 6 个数
print(s)                  # {1, 2, 3}   重复的自动没了！
print(len(s))             # 3
print(3 in s)             # True，in 判断在不在，超快
```

> ⚠️ 集合的三个特点：**去重**（相同元素只留一个）、**无序**（没有下标，`s[0]` 会报错！）、**元素要"能哈希"**（数字、字符串可以，**列表不行**）。想取元素？用 `in` 判断在不在，或用循环遍历。

## ✨ 去重利器：list(set(nums))

把列表转成集合，重复元素立刻消失，再转回列表，就完成了"去重"——这是集合最常用的场景，面试也爱考：

```python
nums = [5, 3, 5, 2, 3, 1, 5]
unique = set(nums)
print(len(unique))        # 4，4 个不重复的数
print(sorted(unique))     # [1, 2, 3, 5]，sorted 排好序并转成列表

a = {}
print(type(a))            # <class 'dict'>   糟了，{} 是空字典！
b = set()
print(type(b))            # <class 'set'>    这才是空集合
```

> ⚠️ 记牢：**`{}` = 空字典，`set()` = 空集合**。有元素的集合用 `{1, 2, 3}` 没问题，创建**空的**必须用 `set()`。

## 🛠️ 增删元素：add、remove、discard

往袋子里扔、往外掏：

```python
s = {1, 2, 3}
s.add(4)              # 加一个
s.add(4)              # 再加 4？没用，本来就有一个
print(s)              # {1, 2, 3, 4}，还是 4 个

s.remove(3)           # 删除：3 不在的话会报错！
s.discard(99)         # 删除：99 不在？不报错，当无事发生
print(s)              # {1, 2, 4}
```

> ⚠️ `remove` 删不存在的元素**会报错**（KeyError），`discard` 不会。不确定元素在不在，用 `discard` 更安全。

## 🤝 交集、并集、差集：集合的灵魂操作

多个集合之间能做数学运算，这是集合最强大的地方：

```python
a = {1, 2, 3, 4}
b = {3, 4, 5}
print(a & b)     # {3, 4}              交集：两边都有的
print(a | b)     # {1, 2, 3, 4, 5}     并集：合在一起，去重
print(a - b)     # {1, 2}              差集：a 有 b 没有的
print(2 in b)    # False
```

> 💡 符号记法：`&` 像 "and"（都要有），`|` 像 "or"（有一个就行），`-` 是"减掉"。也可以用英文方法：`a.intersection(b)`、`a.union(b)`、`a.difference(b)`，效果一样。判断包含关系用 `a <= b`（a 是 b 的子集）。写代码时符号和英文方法随便用，符号更短。
