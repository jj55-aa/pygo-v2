# 列表——能装很多东西的购物车

## 🛒 列表就是能装很多东西的购物车

想象你去超市，手里推着一辆购物车：往里放薯片、放牛奶、放面包，想放多少放多少，还能按顺序一件件加。Python 里的**列表（list）**就是这辆购物车——一块**能按顺序装多个数据**的空间。别的变量一次只能装一个值，列表能装一车！

创建列表用**方括号 `[]`**，里面的元素用**逗号隔开**。元素可以是数字、字符串，甚至可以混合着放：

```python
cart = ["薯片", "牛奶", "面包"]   # 一个装了三样东西的列表
print(cart)                       # ['薯片', '牛奶', '面包']
print(len(cart))                  # 3，购物车里有 3 样东西

a = [1, 2, 3]              # 全是数字
b = ["苹果", "香蕉"]        # 全是字符串
c = [1, "hello", 3.14]     # 混合装，没问题
empty = []                 # 空购物车
```

> 💡 和变量一样，列表名也要**见名知意**：装学生分数就叫 `scores`，装购物车物品就叫 `cart`。

## 🔢 按下标取元素：从 0 开始数！

购物车里的东西有顺序，Python 给每个位置编了号，这个编号叫**下标（索引）**。注意！**下标从 0 开始**，不是 1：

```python
cart = ["薯片", "牛奶", "面包"]
print(cart[0])    # 薯片（第 1 个，下标 0）
print(cart[1])    # 牛奶（第 2 个，下标 1）
print(cart[2])    # 面包（第 3 个，下标 2）
print(cart[-1])   # 面包（负数下标：-1 是最后一个）
```

> ⚠️ 新手最常犯的错：以为第 1 个是 `cart[1]`，结果拿到的是第 2 个。**记住：`[0]` 才是第一个！** 下标超出范围（比如只有 3 格的购物车却取 `cart[10]`）会报 `IndexError`——购物车只有 3 格，你非要拿第 11 格的东西，当然拿不到。

## 🔪 切片：起点要、终点不要

**切片（slice）**能一次取出一段元素，就像切西瓜，想切哪段切哪段。语法：`列表[起点:终点:步长]`。

```python
nums = [0, 1, 2, 3, 4, 5]
print(nums[1:4])     # [1, 2, 3]   从下标1到4，注意：不包含4！
print(nums[:3])      # [0, 1, 2]   不写起点，默认从0开始
print(nums[3:])      # [3, 4, 5]   不写终点，默认到末尾
print(nums[::2])     # [0, 2, 4]   步长为2，隔一个取一个
print(nums[::-1])    # [5, 4, 3, 2, 1, 0]  步长为-1，整个倒过来！
```

> ⚠️ 切片的**终点是取不到的**：`nums[1:4]` 只取下标 1、2、3，**不含 4**（数学上叫"左闭右开"）。这是切片最容易搞混的地方。口诀：**起点要，终点不要，步长管跳不跳**。

## 🧰 增删改查：购物车的日常操作

列表最强大的地方是**可以随便改**——加东西、删东西、换东西都行：

```python
cart = ["薯片", "牛奶"]
cart.append("面包")      # 增：加到末尾
cart.insert(0, "酸奶")   # 增：插到指定位置（下标0）
cart[1] = "橙汁"         # 改：把下标1的薯片换成橙汁
cart.remove("面包")      # 删：按"值"删除第一个匹配的
cart.pop()               # 删：删除并返回最后一个（牛奶）
print(cart)              # ['酸奶', '橙汁']

scores = [88, 92, 75]
for s in scores:         # for 循环挨个拿出每个元素
    print("成绩：", s)
```

> ⚠️ `remove` 删的是"值"，`pop` 删的是"位置"。还有几个好帮手：`sort()` 从小到大排序、`count(x)` 统计次数、`sum()` 求和、`max()` 求最大、`in` 判断在不在。注意 `sort()`/`reverse()` 会**直接改原列表**，想"排序但不改原列表"用 `sorted(a)`。
