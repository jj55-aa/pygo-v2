# 字典——贴了标签的储物柜

## 🗄️ 字典就是贴了标签的储物柜

想象体育馆里的一排储物柜，每个柜门上都贴着名字标签："小明"、"小红"……你要拿小明的书包，不用挨个打开找，直接看标签走过去就行。Python 里的**字典（dict）**就是这排储物柜——存的是**键值对（key: value）**：**键（key）是标签，值（value）是柜子里的东西**。

```python
player = {"名字": "小明", "等级": 5, "金币": 100}
print(player["名字"])     # 小明，按标签（键）取东西
print(player["金币"])     # 100
print(len(player))        # 3，三个键值对

d = {"name": "小明", "age": 18}
print(d["name"])          # 小明
```

> 💡 列表按下标取（`a[0]`），字典按"名字"取（`d["name"]`）。**列表是"第几个"，字典是"叫什么"**。字典的**键必须唯一**，值可以随便重复。

## 🔍 安全查值：get() 与 KeyError

用 `d[键]` 取一个不存在的键，会直接报 **KeyError**！不确定键在不在，就用 `get()`——不报错，还能给默认值：

```python
d = {"name": "小明", "age": 18}
print(d.get("name"))            # 小明，键存在，返回它的值
print(d.get("height"))          # None，键不存在返回 None，不报错！
print(d.get("height", 170))     # 170，键不存在时返回默认值
print("name" in d)              # True，in 判断键在不在
```

> ⚠️ `d["不存在的键"]` 会报 KeyError；**`get(键, 默认值)` 更安全**。写查数据的代码，优先用 get！

## ✏️ 增删改：d[键] = 值、pop、del

增和改都是 `d[键] = 值`——Python 自己判断是新增还是修改：

```python
d = {"name": "小明"}
d["age"] = 18          # 键不存在 → 新增
d["age"] = 19          # 键已存在 → 修改
print(d)               # {'name': '小明', 'age': 19}

d.pop("age")           # 删除并返回该键的值
del d["name"]          # 只删除，不返回
print(d)               # {}
```

> 💡 `d[键] = 值` 一句通吃增和改：**键不存在就是新增，键存在就是修改**。`pop(键)` 删除并返回，`del d[键]` 只删除。

## 🔁 遍历字典：keys / values / items

三种遍历方式，对应三个方法：

```python
d = {"语文": 90, "数学": 85, "英语": 95}
for k in d.keys():          # 遍历所有键
    print(k)                # 语文 数学 英语

for v in d.values():        # 遍历所有值
    print(v)                # 90 85 95

for k, v in d.items():      # 键值对一起拿（最常用！）
    print(k, v)
# 语文 90
# 数学 85
# 英语 95
```

> 💡 `items()` 配两个变量的循环是字典遍历的**标准姿势**，配合 f-string 输出报告超好用。经验法则：数据有"名字"（属性、编号）就用字典；只是一堆东西就用列表。
