# 域名与网络——让用户找得到你

## 🚪 域名就是门牌：发射台的"招牌"

上一课你把服务器（火箭）买好并配好了，但它只有一个**公网 IP**——一串像 `47.98.12.34` 这样的数字。机器之间认的就是这串数字，可人哪记得住？总不能每次访问都背一串数字吧。

**类比**：IP 是发射台在互联网上的坐标，域名（Domain Name）就是人给这个坐标起的**好记的名字**——挂在发射台上的那块"招牌"。用户看到 `pylearn.com` 就知道来找你，不用记 `47.98.12.34`。

**定义**：域名是 IP 地址的"好记名字"，**全球唯一**——一个域名一旦被人注册，全世界只有他能用。注意：域名是**按年租**的，不是买断，忘了续费会被别人抢走。

```python
# 模拟：你的服务器公网 IP（上一课买到的"火箭"）
server_ip = "47.98.12.34"

# 给它起个好记的名字（域名）——这就是你的"招牌"
domain = "pylearn.com"

print("机器之间认：" + server_ip)
print("用户记得住：" + domain)
```

> ⚠️ 新手最容易踩的坑：
> 1. **域名 ≠ 服务器**：域名是"名字"，服务器是"机器"，是两样分开买、分开管的东西。
> 2. 域名**全球唯一且按年租**：想好名字趁早注册，开自动续费，别让好名字过期被抢。
> 3. 光有域名**还连不上服务器**——必须做"解析"（第 3 张卡），把名字指向那台机器。

## 🗣️ DNS 翻译官：域名 → IP 的超级通讯录

用户输入 `pylearn.com` 后，浏览器怎么知道该去哪台服务器？靠的是 **DNS**（Domain Name System，域名系统）。

**类比**：DNS 就像一本**超大的通讯录**，左边记着名字（域名），右边记着号码（IP）。用户一输入域名，网络就先翻这本通讯录，查到对应的 IP，再把用户送到那台服务器。DNS 就是发射台的"翻译官"。

**定义**：DNS（域名系统）负责把域名翻译成 IP 地址。你输入 `pylearn.com`，DNS 查通讯录返回 `47.98.12.34`，浏览器再去找那台服务器。

```python
# 模拟 DNS 通讯录：左边域名，右边 IP
dns_book = {
    "pylearn.com": "47.98.12.34",
    "rocket.cn": "120.55.88.99",
}

# 用户输入域名，翻译官查通讯录
name = input("输入要访问的域名：")
print(name, "→", dns_book.get(name, "查不到，域名不存在"))
```

> ⚠️ 新手最容易踩的坑：
> 1. **机器之间认的是 IP，不是域名**——没有 DNS 翻译，域名就是个摆设。
> 2. 通讯录里**查不到**（没做解析）时，浏览器会报"无法访问"，不是网站坏了，是没人翻译。
> 3. 现实中的 DNS 是遍布全球的分布式系统，这里用字典模拟它的"查表"思想。

## 🧾 解析记录：把"招牌"挂到服务器上（A 记录）

域名买来了，服务器也买来了，可他俩**还不认识**。你得亲手往 DNS 通讯录里写一条："我的域名 → 我的服务器 IP"。这一步就叫**解析**。

**类比**：解析就是**给招牌写上地址**——不然用户看到你的名字，也不知道该往哪儿走。做解析 = 亲手往通讯录里写一条映射规则，这条规则叫**解析记录**。

**定义**：解析记录是域名后台里的一条条"映射规则"。最常用的是 **A 记录**（Address 记录）：把域名**直接指向一个 IP 地址**。配置时记录值要填服务器的**公网 IP**，保存后不是立刻生效，要等几分钟到几小时。

```python
# 模拟：判断一条解析记录（域名,IP）是否有效
def is_public(ip):
    """公网 IP 判断：不是 127./192.168./10. 开头就是公网"""
    if ip.startswith("127.") or ip.startswith("192.168.") or ip.startswith("10."):
        return False
    return True

record = "pylearn.com,47.98.12.34"
domain, ip = record.split(",")
if is_public(ip):
    print(domain, "解析有效")
else:
    print(domain, "解析无效：内网 IP 别人访问不到")
```

> ⚠️ 新手最容易踩的坑：
> 1. **解析必须指向公网 IP**：填了 `192.168.x.x`、`10.x.x.x` 这种内网地址，外面的人永远打不开你的网站。
> 2. **保存 ≠ 生效**：解析要等几分钟到几小时全网才反应过来，期间访问不通是正常的，别急着反复改。
> 3. 一般要把 `@`（域名本身）和 `www` 两条 A 记录都加上，用户输哪个都能进。

## 📋 备案与合规：上线前的"登记手续"

招牌挂好了、解析也配好了，能直接发射了吗？还差一步：**备案**。

**类比**：备案就是发射台向主管部门做的**登记手续**——先报备，才能正式对外营业。

**定义**：ICP 备案是国家要求的登记手续：只要你的域名解析到**中国大陆的服务器**并对外提供服务（网站、API、App 后端、小程序后端都算），**就必须先备案**。没备案，云厂商会直接拦截访问，用户打不开，主管部门也会要求关停。备案要趁早办，首次可能要等两三周；域名还要先做**实名认证**，认证不通过备案也走不了。

```python
# 模拟上线前检查：备案是硬门槛
def launch_check(server_location, icp_done):
    if server_location == "中国大陆" and not icp_done:
        print("还没备案：云厂商会拦截访问，用户打不开！")
    else:
        print("备案没问题，检查通过，可以发射！")

launch_check("中国大陆", False)   # 没备案 → 被拦截
launch_check("中国大陆", True)    # 已备案 → 放行
```

> ⚠️ 新手最容易踩的坑：
> 1. **备案看的是"服务器放在哪"，不是"域名在哪"**：大陆服务器 + 对外服务 = 必须备案；服务器放境外则不用。
> 2. **备案是上线前提**：没备案，解析配得再好用户也打不开——云厂商直接拦截。
> 3. **备案要趁早**：别等代码写完急着上线才发现要备案，干等两三周。
