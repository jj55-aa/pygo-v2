# 认识服务器——发射台的第一课

## 🗼 服务器：发射台的"塔台"

**类比**：想象你在「发射台」发射火箭。火箭（你的项目）造好了，停在自己家的车库里——可谁来看呢？发射台中央有一座**塔台**，里面有一位 24 小时值班的调度员：不管白天黑夜、刮风下雨，只要有人来问，他都在岗。**服务器就是这座塔台**——一台 24 小时开机、24 小时联网、放在机房里的电脑，你的项目放在它上面，别人才能随时随地访问。

**定义**：**服务器** = 永远开机、永远联网、放在机房里、专门对外提供服务的电脑。它和你家里的电脑本质一样，但有三个关键不同：**不关机**（别人半夜也能访问）、**公网 IP 固定**（外面的人总能找到它）、**机房专人维护**（双路供电、专业散热、安全防护）。这就是为什么部署上线绕不开一台服务器。

```python
# 模拟"塔台值班"：服务器 24 小时在线，随时响应
for time in ["凌晨 3 点", "早上 8 点", "深夜 11 点"]:
    print("塔台值班中，收到" + time + "的访问 → 正常响应！")
```

> ⚠️ 新手最容易踩的坑：
> 1. **服务器不是神秘的东西**，它就是一台电脑——关键是"一直开着、一直连网"。你家里的电脑会关机、会休眠、会断网，所以当不了塔台。
> 2. **本地能跑 ≠ 线上能跑**：你的电脑上跑得动，不代表服务器上也能跑（系统、依赖、配置都可能不一样），上线前一定要在服务器上实测。

## 🖥️ 本地 vs 线上：localhost 只有自己能访问

**类比**：**本地**就像你家的客厅——只有你自己（最多家里人）能进；**线上**就像大街上的店面——谁路过都能进来。项目跑在哪，决定了谁能访问它。

**定义**：**本地**：项目跑在你自己电脑上，地址通常是 `localhost`（或 `127.0.0.1`）——**只有你这台电脑自己能访问**。**线上**：项目跑在一台 24 小时在线的服务器上，别人通过它的公网地址访问。网上那个梗「我做了个项目，地址是 localhost」——笑的就是项目还停在本地，**没有部署上线**。

```python
# 本地 vs 线上：先看看项目现在跑在哪
addr = "localhost:3000"
if "localhost" in addr or addr.startswith("127."):
    print("本机：只有自己这台电脑能打开")
else:
    print("线上：别人也能访问")
```

> ⚠️ 新手最容易踩的坑：
> 1. **千万别把 localhost 发给用户/朋友**：`localhost` 在别人的电脑上指向**别人的电脑**——他打开的是他自己，不是你的项目。
> 2. **localhost ≠ 公网地址**：localhost 是"自己家的门牌"，只在你这台电脑上有效；想让全世界访问，得先把项目部署到线上。

## ☁️ 云服务器：租一台远程电脑

**类比**：自己买一台电脑放在机房里，又要交电费、又要找人维护，太麻烦——就像为了看几场电影自己养一头大象。更聪明的办法是**租**：**云服务器**就是向云厂商（阿里云、腾讯云、AWS……）**租一台放在机房里的远程电脑**，24 小时开机，按月付费，随时续租。

**定义**：**云服务器** = 云厂商机房里的远程电脑，有固定的公网 IP，专门跑你的项目对外服务。购买页上的配置，拆开看就是四个词：
- **核心数** = 干活的人手（访问的人越多越需要）
- **内存** = 工作台大小（断电就清空）
- **硬盘** = 长期仓库（代码、数据库、文件都存在这）
- **带宽** = 门口路宽（数据进出的速度）

```python
# 模拟"购买配置单"：核心数=人手，内存=工作台，硬盘=仓库，带宽=门口路宽
config = {"核心数": 2, "内存": "2G", "硬盘": "40G", "带宽": "3M"}
print("我租的服务器：", config)
print("访问量越大，越要加核心和内存。")
```

> ⚠️ 新手最容易踩的坑：
> 1. **云服务器是"租"的不是"买断"**：记得按时续费，欠费会被停机，网站就"失联"了。
> 2. **内存的 G 和硬盘的 G 不是一回事**：内存是"断电清空的工作台"，硬盘是"关机也留着的仓库"，别搞混。

## 🧪 地址识读：本机 / 内网 / 公网

**类比**：塔台检查员手里有一本「地址分类手册」：拿到任何地址，先判断它在哪个访问圈层——**本机**（只有自己）、**内网**（小圈子里的人）、**公网**（互联网上谁都能访问）。这决定了你的项目开放给谁。

**定义**：判断规则（模拟，用字符串判断就够）：
- 含 `localhost` 或以 `127.` 开头 → **本机**（127.0.0.1 就是 localhost）
- 以 `192.168.` / `10.` 开头，或 `172.16`~`172.31` → **内网**（家用路由器、公司网络常用段）
- 其他 → **公网**（互联网上可达）

```python
addr = input().strip()
if "localhost" in addr or addr.startswith("127."):
    print("本机")
elif addr.startswith("192.168.") or addr.startswith("10."):
    print("内网")
else:
    print("公网")
```

> ⚠️ 新手最容易踩的坑：
> 1. **127.0.0.1 是"本机"，不是公网**：它和 localhost 是同一个意思，只有自己这台电脑能访问。
> 2. **172.16~172.31 才是内网**：172 开头不等于全是内网，172.32 以上是公网——判断时要比对第二段数字。
