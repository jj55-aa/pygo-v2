# 前后端分工——网站的门面与账房

## 🏪 前端：饭店的门面

想象你走进一家饭店：招牌、菜单、服务员、点菜的平板——**你能看到、能摸到、能操作的一切**，都是门面。网站也一样：页面上你能看到的按钮、搜索框、图片、弹窗，以及点击、输入、滑动这些交互，都属于**前端**。

前端负责三件事：
1. **渲染页面**：把页面画出来——文字、图片、布局，都是它的活
2. **收集用户输入**：你输入的账号密码、搜索关键词，由它先接住
3. **发请求**：把用户的需求打包成请求，发给后端，再拿回结果展示

```python
# 前端：用户点了一下「查看我的资料」按钮
request = "get_user"              # 把需求打包成请求
print("前端：渲染页面，收集输入")
print("前端：发出请求 →", request)
```

> ⚠️ 新手最容易踩的坑：
> 1. **前端不能直接读数据库**。数据库是账房的账本，前端是门面——想看数据，只能通过后端转交。
> 2. **敏感逻辑不能放前端**：前端代码会下载到用户浏览器里运行，谁都能看到。密码校验、支付这类事必须交给后端。

## 🧮 后端：账房先生

顾客在饭店里看不到账房，但饭店能不能转起来全靠它：账房先生管着**账本**（数据），点菜之后按账本备料、算账、结账。网站里的**后端**，就是用户看不见、但网站运转离不开的部分：

1. **接收请求**：听前端说了什么
2. **处理业务**：判断密码对不对、算订单金额、做各种规则判断
3. **查数据库**：从账本里把需要的数据取出来
4. **返回数据**：把结果打包好，送回前端

```python
# 后端：账房先生收到请求，查账本，返回数据
request = "get_user"
data = {"name": "小明", "level": 3}   # 从「数据库」查到的
print("后端：收到请求", request)
print("后端：查到数据 →", data)
```

> ⚠️ 新手最容易踩的坑：
> 1. **后端不画页面**：页面长什么样是前端的活，后端只负责数据和业务处理，别让它去管「好不好看」。
> 2. **敏感操作必须放后端**：密码校验、支付、写数据库——放前端等于把账房钥匙贴在门上，用户一打开网页就能看到。

## 🌉 API：前后端之间的桥梁

饭店里有个**传菜窗口**：前厅（前端）把点菜单递进去，后厨（后端）把菜端出来。这个窗口有一套约定：什么时候递单、递什么单、端出来什么菜。前后端之间的"传菜窗口"就是 **API（接口）**——前端和后端**约定好的通信方式**：请求什么、带什么参数、返回什么数据。

API 返回数据最常用 **JSON** 格式：长得像字典的文本，机器好读、人也好认。

```python
import json

# API 的约定：请求 get_user → 返回用户数据（JSON 字符串）
data = {"name": "小明"}
resp = json.dumps(data, ensure_ascii=False)   # 字典 → JSON 字符串
print(resp)   # {"name": "小明"}
```

> ⚠️ 新手最容易踩的坑：
> 1. **API 返回的是数据，不是页面**：前端拿到的是一份 JSON，页面得前端自己画。
> 2. **接口没商量好就各写各的**：前端以为字段叫 `name`，后端返回的却是 `user_name`——页面就显示不出来了。所以先约定 API，再各自开工。

## 🔄 一次完整分工：从点按钮到看到结果

把前面的拼起来，一次请求的完整流程：

1. 前端渲染页面，用户点击「查看资料」
2. 前端发出请求 `get_user`
3. 后端收到请求，查数据库、处理业务
4. API 把结果打包成 JSON 返回
5. 前端收到 JSON，渲染到页面上

```python
import json

# ① 前端：用户点击按钮，发出请求
request = "get_user"
print("① 前端发请求：", request)

# ② 后端：收到请求，查数据库
data = {"name": "小明"}
print("② 后端查数据：", data)

# ③ API：打包成 JSON 返回
resp = json.dumps(data, ensure_ascii=False)
print("③ API 返回：", resp)

# ④ 前端：拿到数据，展示页面
print("④ 前端展示：你好，" + data["name"] + "！")
```

> ⚠️ 新手最容易踩的坑：
> 1. **顺序不能乱**：先请求、后返回。前端必须**等**后端的数据，不能跳过 API 自己编数据骗用户。
> 2. **一句话记住分工**：前端要数据、后端给数据、API 传数据——各司其职，网站才能转起来。
