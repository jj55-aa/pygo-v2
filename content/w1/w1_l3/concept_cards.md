# 网络常识——新大陆的地图

## 🏠 IP 地址——新大陆的"门牌号"

**类比**：想象「网络新大陆」是一座巨大的城市。每一台设备——你的电脑、手机、网站服务器——都是城市里的一座房子。房子要有**门牌号**，别人才能找到你；设备要有**IP 地址**，网络才能找到它。

**定义**：**IP 地址**就是每台设备在网络上的地址，像门牌号一样（一台设备可以有好几块"门牌"，比如 WiFi 下一块、流量下一块）。最常见的 IPv4 长这样：`192.168.1.8`——4 段数字，用点 `.` 隔开，每段 0~255。

```python
ip = "192.168.1.8"
parts = ip.split(".")        # 按点切开 → ["192", "168", "1", "8"]
print("第 1 段：", parts[0])
print("第 2 段：", parts[1])
print("第 3 段：", parts[2])
print("第 4 段：", parts[3])
```

> ⚠️ 新手最容易踩的坑：
> 1. **IP 地址 ≠ 网址**：IP 是数字门牌（`192.168.1.8`），网址是给人记的名字（`www.example.com`），两者靠 DNS 对应起来。
> 2. **同一台设备在不同网络下门牌会变**：连家里 WiFi 是一个内网地址，用手机流量又是另一个——地址是"在哪个网络里"的地址。

## 📖 域名与 DNS——"通讯录"翻译官

**类比**：你记不住朋友的电话号码，但记得住他的名字——翻通讯录一查，号码就有了。电脑正好反过来：它记不住 `www.example.com` 这种名字，只认 `93.184.216.34` 这种数字。**DNS 就是互联网的通讯录**：你报上名字，它翻译出数字。

**定义**：**域名**是给网站起的好记名字（`www.example.com`、`www.python.org`）；**DNS（Domain Name System，域名系统）**负责把域名**解析**成对应的 IP 地址。你在浏览器输入域名，浏览器先问 DNS"这个域名在哪台服务器"，拿到 IP 才出发。

```python
# 模拟一本迷你 DNS 通讯录：域名 → IP
dns = {
    "www.example.com": "93.184.216.34",
    "www.python.org": "151.101.0.223",
}
domain = "www.example.com"
print(domain, "的 IP 是", dns[domain])   # 翻译官出马！
```

> ⚠️ 新手最容易踩的坑：
> 1. **域名不能直接定位，必须先 DNS 解析**：没有 DNS 这本通讯录，浏览器拿到 `www.example.com` 也不知道该去哪台服务器。
> 2. 域名和 IP 不是一对一：一个域名可以对应多台服务器（分摊访问），一台服务器也能挂多个域名。新手阶段记住「**名字 → 数字**」这条翻译链就够啦。

## 🚪 localhost 与端口——自己家 + 门牌号

**类比**：`localhost`（也可以写 `127.0.0.1`）就是"**我自己这台电脑**"——不是互联网上某个公开的网站，而是你面前这台机器自己。而一台电脑上能同时跑很多个服务（网页、聊天机器人、游戏后端……），怎么区分？靠**端口**：端口就是设备上的**服务门牌号**。一栋大楼（一台设备）可以有很多房间（服务），房间号就是端口。

**定义**：**localhost / 127.0.0.1** = 本机自己的地址，**只有这台电脑自己能访问**；**端口（port）** = 设备上不同服务的门牌号。常见端口：`80` 网页（HTTP）、`443` 加密网页（HTTPS）、`3000` 常是开发服务器。网址里 `:` 后面的数字就是端口：`http://localhost:3000` 表示"访问本机上 3000 号房间的服务"。

```python
address = "localhost:3000"
host, port = address.split(":")
print("主机：", host)     # localhost → 自己这台电脑
print("端口：", port)     # 3000 → 服务的门牌号
```

> ⚠️ 新手最容易踩的坑：
> 1. **localhost 只有你自己能访问**：把它当网址发给朋友，朋友打开的是**他自己的电脑**——他电脑上没跑你的项目就打不开。网上那个梗「我做了个项目，地址是 localhost」笑的就是这个。
> 2. **端口不是密码，是门牌号**：`http://localhost:3000` 里的 `3000` 不是登录密码，而是"这栋楼的 3000 号房间"。想让外面的人访问，光靠 localhost 可不行，那是下一站「部署上线」的事。

## 🌐 公网 vs 内网——大门朝外 vs 院子里

**类比**：把网络访问范围想成四层圈：**自己屋里**（localhost，只有你自己）→ **院子里的小圈子**（内网/局域网，比如家里 WiFi、公司网络，圈子里的人能找到你）→ **大街上**（公网，任何地方的陌生人敲你的门都能进来）。判断标准不是设备放在哪，而是**它到底开放给谁访问**。

**定义**：**内网/局域网地址**一般是 `192.168.x.x`、`10.x.x.x` 这类——同一 WiFi 下的手机能通过电脑的 `192.168.1.8:3000` 访问你的项目，但圈子外的人进不来；**公网地址**是互联网上所有人都能访问的地址。**暴露面**越大（能被越多的人访问），风险通常越高：localhost < 内网 < 公网。

```python
ip = input("输入一个 IP：")
if ip == "127.0.0.1":
    print("本机：只有你自己能访问")
elif ip.startswith("192.168."):
    print("内网：同一个小圈子里的人能访问")
else:
    print("可能是公网：外面的人都能访问")
```

> ⚠️ 新手最容易踩的坑：
> 1. **别把 localhost 发给别人**：`localhost` 在别人电脑上指向的是别人自己——想让别人访问，得先把项目部署到公网/内网可达的地方。
> 2. **内网 ≠ 绝对安全**：同一 WiFi、同一公司网络的设备都能访问到它；代码本身不安全的话，圈子被攻破一样会泄漏数据。暴露面越小越稳妥，但不能因为"在内网"就不管安全。
