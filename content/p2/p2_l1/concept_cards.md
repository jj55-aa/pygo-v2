# 抓取与解析——织起影评峡谷的第一张网

## 🕸️ 爬虫四步走：把网撒出去，把数据收回来

你走进影评峡谷，两壁的石碑上刻着密密麻麻的电影名和评分——可惜全是 HTML 源码，肉眼根本读不出「哪部值得看」。峡谷的老猎人递给你一捆蛛丝：「想让 Python 替你把数据抓下来，得先学会**织网**。爬虫抓数据，有固定的**四步走**。」

- **① 发请求**：向服务器「撒网」——告诉服务器：把网页给我
- **② 拿响应**：服务器把网页内容「收进网里」——拿到的就是**网页源码**（一段 HTML 字符串）
- **③ 解析**：拆开这张网，按标签的形状找数据（本课重点）
- **④ 提取数据**：把找到的数据清洗、统计、保存

Python 里 `requests` 就是爬虫的「织网工具」：`requests.get(网址)` 发请求，拿到响应对象后，它的 `.text` 就是网页源码。**注意**：咱们的判题环境（Pyodide）没有 requests、也没有网络——完整流程先记牢概念；练习时题目会**直接给你一段 HTML 字符串**（相当于已经拿到的响应），你从第 ③ 步开始练。

```python
# 爬虫四步走（概念版）
# ① 发请求 → requests.get(网址) 向服务器要网页
# ② 拿响应 → 响应 .text 就是网页源码（HTML 字符串）
# ③ 解析   → 按标签形状找数据（本课重点）
# ④ 提取   → 清洗、统计、保存
# 判题环境（Pyodide）没有 requests、没有网络，
# 所以练习直接用题目给的 HTML 字符串，从第 ③ 步开始练。

html = '<p class="title">肖申克的救赎</p>'
print("拿到响应：", html)
```

> ⚠️ 新手最容易踩的坑：
> 1. **顺序不能乱**：解析和提取的对象是「响应」里的网页源码——网都还没撒出去（没发请求），拿什么解析？
> 2. **判题环境没有 requests**：Pyodide 里 `import requests` 会报 ModuleNotFoundError；练习用「给定的 HTML 字符串」当响应，别真去联网。

## 🧱 电影页 HTML 长什么样：标签是货架，class 是标签

网页在浏览器里是花花绿绿的页面，但在爬虫眼里，它只是一段**HTML 字符串**。HTML 的骨架是**标签**：标签成对出现，`<p>` 是开始标签，`</p>` 是结束标签（结束标签多一个斜杠 `/`），要抓的数据就夹在两者中间。

影评峡谷的「电影条目」长这样——`<div class="movie">` 是一个**容器**（货架格），里面装着两个小标签：

- `<p class="title">肖申克的救赎</p>`：`p` 是段落标签，装**片名**
- `<span class="score">9.7</span>`：`span` 是行内标签，装**评分**

这里的 `class="title"`、`class="score"` 是**属性**：`class` 给标签「分组起名」，同名的一组数据就可以一起抓。就像货架上的隔板标签——「title 区」放片名、「score 区」放评分，一目了然。

```python
# 影评峡谷「电影条目」骨架：div 是容器，p 装片名，span 装评分
print("<div class='movie'>")                 # 一部电影的「货架格」
print("  <p class='title'>片名</p>")        # 片名标签
print("  <span class='score'>评分</span>")  # 评分标签
print("</div>")
```

> ⚠️ 新手最容易踩的坑：
> 1. **class 属性名必须一字不差**：`class="title"` 写成 `class="titel"`、多一个空格，正则就一个都匹配不到——HTML 字符串匹配不认「差不多」。
> 2. **标签要成对**：`<p>` 开头必须配 `</p>` 结尾（带斜杠），数据夹在中间；只写开始标签，正则找不到结束位置。

## 🏷️ 提取片名：`<p class="title">(.*?)</p>`

片名藏在 `<p class="title">片名</p>` 里，怎么把它们一条条捞出来？用**正则表达式**（`re` 模块）——它像一把「定制形状的钥匙」，只要形状对得上，一次能撬开**所有**同款的锁。

```python
import re

html = '''<p class="title">肖申克的救赎</p>
<p class="title">星际穿越</p>'''
titles = re.findall(r'<p class="title">(.*?)</p>', html)
for t in titles:
    print(t.strip())
```

逐字拆解这把「钥匙」：

- `re.findall(模式, 文本)`：把文本里**所有**匹配的内容放进一个列表（不是只找第一个）
- `(.*?)`：**分组** + **非贪婪**——括号把要的内容圈出来；`?` 让 `.*` 尽量少匹配，遇到最近的 `</p>` 就停，不会一口气吞掉后面的片名
- `t.strip()`：去掉内容首尾的多余空白（缩进、换行）

> ⚠️ 新手最容易踩的坑：
> 1. **别用贪婪 `.*`**：`<p class="title">(.*)</p>` 会从第一个 `<p class="title">` 一直吃到**最后一个** `</p>`，把好几部片名连同中间标签全吞成一个。
> 2. **`re.findall` 不是 `re.search`**：`search` 只返回第一个匹配；要「所有」片名必须用 `findall`。
> 3. **跨行内容要加 `re.S`，捞出来要 `strip()`**：`.` 默认不匹配换行——标签内容跨行（片名和 `</p>` 不在同一行）时，正则要加第三个参数 `re.S` 才捞得到；捞出来的内容还带着换行缩进，打印前用 `t.strip()` 清洗。

## ⭐ 提取评分：`<span class="score">(.*?)</span>`

片名捞出来了，评分还躺在 `<span class="score">9.7</span>` 里。方法一模一样——换一把「评分钥匙」就行：

```python
import re

html = '''<span class="score">9.7</span>
<span class="score">9.4</span>'''
scores = re.findall(r'<span class="score">(.*?)</span>', html)
for s in scores:
    print(s.strip())   # 先清洗；转成数字做统计，是下一站的事
```

- `r'<span class="score">(.*?)</span>'`：`span` 标签 + `class="score"` 属性锁定评分，`(.*?)` 非贪婪取出分数
- 捞出来的 `"9.7"` 是**字符串**：直接和数字比大小（`"9.7" > 9.0`）会出错，统计前要 `float()` 转数字——下一课「提取与统计」专门练这个

> ⚠️ 新手最容易踩的坑：
> 1. **class 写错会「静默失败」**：`score` 写成 `scroe`，`findall` 返回**空列表**，一个评分都捞不到，而且不报错——看起来「跑通了」，结果却是空的，最坑。
> 2. **属性里的空格别自己加**：题目给的是 `class="score"`，正则就照抄 `class="score"`；写成 `class = "score"`（加了空格）就匹配不上了。
> 3. **评分是字符串**：先 `strip()` 清洗；要比较、统计时再 `float()` 转换，别拿字符串直接算。
