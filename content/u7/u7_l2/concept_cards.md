# CSV 与 Excel——给档案排一张电子表格

## 📄 CSV 是表格界的纯文本

档案馆的卷宗堆积如山，馆长拍板：全部转成电子表格！可几十年前的档案，有的在记事本里、有的在 Excel 里、有的只有一张纸——到底用什么格式存，才能让**任何软件都能打开**？

答案就是 **CSV**（Comma Separated Values，逗号分隔值）。它本质上就是一个**纯文本文件**，只不过用逗号把一列一列的数据分开。用记事本打开长这样，用 Excel 打开它又变成一张表格：

    编号,标题,存放柜
    A001,借阅登记表,3号柜
    A002,修复日志,5号柜

这就是 CSV 最大的优点：**任何电脑、任何软件、任何语言都能读**，所以它成了数据交换的"通用语言"。在 Python 里，标准库自带 `csv` 模块，不用安装，配合 `io.StringIO`（把字符串包装成"虚拟文件"）就能在内存里直接解析：

```python
import csv
import io

csv_text = "编号,标题,存放柜\nA001,借阅登记表,3号柜\nA002,修复日志,5号柜"
reader = csv.reader(io.StringIO(csv_text))
for row in reader:
    print(row)
```

运行输出三行，每行是一个**列表**：

    ['编号', '标题', '存放柜']
    ['A001', '借阅登记表', '3号柜']
    ['A002', '修复日志', '5号柜']

看到了吗？`reader` 把每一行变成一个列表，一个元素就是一列。

> ⚠️ 新手最容易踩的坑：
> 1. **CSV 读出来全是字符串**！`'18'` 是字符串，不是数字 18。想算数，先 `int()` / `float()` 转一下。
> 2. **中文要指定编码**：读真实文件时写 `encoding="utf-8"`，否则中文变乱码（想用 Excel 打开不乱码，用 `utf-8-sig`）。
> 3. **别手拼 CSV**：数据里万一有逗号（比如地址"北京,朝阳区"），你手动拼字符串就会裂开——用 `csv.writer`，它会自动帮你加引号包好。

## 📖 csv.reader：一行行把 CSV 读成列表

读档案不能一页一页抄，得有"翻页器"。`csv.reader` 就是那个翻页器：给它一个"文件对象"，它一次给你一行——每一行是一个列表，列表里每个元素就是一列。

那字符串怎么给它？用 `io.StringIO(文本)` 把字符串包装成"虚拟文件"。判题环境文件系统受限、不能落盘，用这招就能在内存里读写 CSV：

```python
import csv
import io

text = "书名,借阅数\n《Python入门》,12\n《档案管理》,8"
rows = list(csv.reader(io.StringIO(text)))   # 一次全读出来，存进列表
print(rows[0])          # 表头
print(rows[1][0])       # 第一行数据的书名（第 2 行第 1 列）
print("数据行数：", len(rows) - 1)
```

运行输出：

    ['书名', '借阅数']
    《Python入门》
    数据行数： 2

- `list(reader)`：把迭代器**一次性**变成列表，之后想怎么翻就怎么翻
- `rows[1]` 是第 2 行（第 0 行是表头），`row[0]` 是这一行的第 1 列——**下标从 0 开始数**

> ⚠️ 新手最容易踩的坑：
> 1. **reader 是迭代器，读完一遍就空了**！`for row in reader` 跑完后，再想循环一次会发现什么都没有——先用 `list()` 存起来。
> 2. **下标从 0 数**：`row[0]` 是第一列，别把表头那行算进数据里（数据从 `rows[1:]` 开始）。
> 3. `csv.reader` 要的是"文件对象"：字符串不能直接喂给它，得先 `io.StringIO(字符串)` 包一层；真实文件则用 `open()` 返回的文件对象。

## 📊 Excel 的结构：工作簿、工作表、单元格

CSV 只能存干巴巴的数据，Excel 就不一样了：能存**样式**、**公式**、**多张表**。想象档案馆那个三层大书架：

- **工作簿（Workbook）**：整个 `.xlsx` 文件，就像一本《馆藏总账》
- **工作表（Worksheet）**：书里的每一页，一个文件可以有好几页（左下角的 Sheet1、Sheet2……）
- **单元格（Cell）**：书页上的一个小格子，用**坐标**定位：列是字母 A、B、C……，行是数字 1、2、3……

一个格子的坐标就是"列字母 + 行数字"，比如 **A1** 就是第一列第一行。Python 操作 Excel 最常用的库是 **openpyxl**——但它**不是自带的标准库**，得先 `pip install openpyxl` 装上才能 `import openpyxl`。

判题环境（Pyodide）没有 openpyxl，所以我们先用**列表模拟表格**把结构搞懂：每个小列表 = 一行，`ws[行-1][列-1]` 就相当于 Excel 里的坐标：

```python
# 用列表模拟一张"工作表"：每个小列表 = 一行
ws = [
    ["书名", "借阅数"],        # 第 1 行
    ["《Python入门》", 12],   # 第 2 行
    ["《档案管理》", 8],      # 第 3 行
]
print(ws[1][0])   # 第 2 行第 1 列，相当于 Excel 的 A2
print(ws[1][1])   # 第 2 行第 2 列，相当于 Excel 的 B2
```

运行输出：

    《Python入门》
    12

> ⚠️ 新手最容易踩的坑：
> 1. **openpyxl 是"装来"的第三方库**：没 `pip install openpyxl` 就 `import openpyxl`，会报 `ModuleNotFoundError`。
> 2. **本课判题环境没有 openpyxl**：code 题里别 import 它，用列表/字典模拟表格，或用 csv 模块处理。
> 3. **Excel 的行列从 1 开始数**（A1 是第一格）；用列表模拟时记得减 1：`ws[行-1][列-1]`。

## ⚖️ CSV vs Excel：怎么选？

档案馆里什么样的档案用 CSV，什么样的用 Excel？记住这条口诀：**简单通用用 CSV，好看好用用 Excel**。

| 需求 | 选谁 | 为什么 |
| --- | --- | --- |
| 给程序用、要通用、要轻量 | **CSV** | 纯文本，记事本能开，任何语言都能读 |
| 给人看、要颜色/公式/多张表 | **Excel** | `.xlsx` 里有样式、公式、多工作表 |
| 数据里有嵌套结构（列表套字典） | **都别用** | CSV 和 Excel 都是"矩形"，存不下嵌套——那是下一课 JSON 的地盘 |

openpyxl 就是操作 Excel 的"翻译官"：`load_workbook("馆藏总账.xlsx")` 打开工作簿、`wb.active` 拿默认工作表、`ws["A1"].value` 取单元格的值——全套都要先 `pip install openpyxl` 才用得了。

先动手用 csv 把档案整理起来，跳过表头逐行输出：

```python
import csv
import io

text = "姓名,部门\n林小满,档案部\n顾远山,修复部"
rows = list(csv.reader(io.StringIO(text)))

for row in rows[1:]:        # 跳过表头
    print(row[0], "在", row[1])
```

运行输出：

    林小满 在 档案部
    顾远山 在 修复部

> ⚠️ 新手最容易踩的坑：
> 1. **别拿 CSV 存样式**：CSV 只有数据没有格式，想加颜色/加粗/公式，选 Excel（openpyxl）。
> 2. **别拿 Excel 当"通用交换格式"**：`.xlsx` 是专有的压缩包格式，记事本打不开；给程序传数据，CSV 更省心。
> 3. **嵌套数据别硬塞表格**：CSV/Excel 只能存"矩形"，一行一行的；遇到嵌套结构，直接想 JSON（下一课）。
