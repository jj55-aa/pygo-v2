# 分支结构——让程序学会"看情况办事"

## 🛤️ 程序走到了岔路口

前面学的代码都是**从上往下一条一条执行**，这叫**顺序结构**。但现实生活哪有这么直？早上出门前你会**看天气**：下雨就带伞，不下雨就空手出门。程序也一样：**根据条件决定走哪条路**，这种结构叫**分支结构**（也叫选择结构）——编程里最常用的套路，学会了它，程序才真正"有脑子"。

```python
print("出门")          # 顺序结构：从上往下，一句一句执行
print("到学校")
```

## 🌱 if 语句：满足条件才执行

最简单的分支：**条件成立就执行，不成立就跳过**。用 `if` 关键字，条件后面必须写**冒号 `:`**，要执行的代码必须**缩进**（Tab 或 4 个空格）：

```python
score = 85
if score >= 60:
    print("及格了！")      # 条件成立，输出：及格了！
print("程序结束")          # 这行没有缩进，不属于 if，永远执行
```

三个最容易栽的坑：
- ⚠️ **坑1：别忘了冒号**。`if` 后面的条件写完，必须以 `:` 结尾。
- ⚠️ **坑2：缩进就是代码块**。Python 用缩进表示"这句话属于 if"，缩进错了，程序要么报错，要么逻辑全乱。
- ⚠️ **坑3：判断相等用 `==`，别写成 `=`**。`if score = 60` 是赋值，直接报语法错误。

如果 `score = 50`，条件不成立，`print("及格了！")` 被跳过，只输出"程序结束"。

## 🔀 if...else：二选一

"满足条件做 A，不满足做 B"才是常态。就像景区售票窗口：成年卖成人票，没成年卖儿童票：

```python
age = 15
if age >= 18:
    print("买成人票")
else:
    print("买儿童票")      # 输出：买儿童票
```

`else` 就是"否则"：**if 条件不成立时执行它下面的代码**。if 和 else 就像硬币的两面，总有一面会被执行。

## 🪜 if...elif...else：多选一

成绩要分"优秀/良好/及格/不及格"四档怎么办？用 `elif`（else if 的缩写）：

```python
score = 75
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")          # 输出：及格
else:
    print("不及格")
```

执行规则记死：**从上往下，找到第一个成立的条件就执行，然后整段"下班"**。75 分不满足 `>=90`、`>=80`，但满足 `>=60`，输出"及格"。

> ⚠️ **常见坑：条件顺序写反**。把宽泛的条件写在前面，后面的永远没机会执行——95 分如果先撞上 `score >= 60`，就会被拦在"及格"这一档。**多分支条件要"从严格到宽松"写**（先 >=90，再 >=80……），像漏斗一样。

## 🧩 逻辑运算符与真假值：把条件串起来

一个条件不够用怎么办？比如"分数在 80 到 90 之间"要同时满足两个条件。用**逻辑运算符**把条件串起来：

| 运算符 | 含义 | 例子 |
| --- | --- | --- |
| `and` | 并且（两边都为真才真） | `score >= 80 and score <= 90` |
| `or` | 或者（一边为真就真） | `x < 0 or x > 100` |
| `not` | 取反（真的变假，假的变真） | `not is_raining` |

```python
score = 85
if score >= 80 and score <= 90:      # 两个条件同时成立
    print("成绩不错，在 80~90 之间")   # 输出这一行
if not score < 60:                   # 取反：不小于 60
    print("及格了")
```

> ⚠️ **真假值小知识**：在 if 里，**0、空字符串 ""、空列表 [] 会被当作"假"**，其他大部分值都是"真"。所以 `if x:` 和 `if x != 0:` 常常等价；判断"x 是不是 0"可以写 `if not x:`。
