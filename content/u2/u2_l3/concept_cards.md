# 分支和循环的应用——组合拳实战

## 🎯 实战一：猜数字游戏（循环 + 判断的组合拳）

前两课学了分支（if）和循环（for / while），这一课把它们**组合起来打实战**。真实的程序几乎都是"循环里套判断、判断里套循环"，两者像筷子，缺一根都不好使。

先看猜数字游戏：程序想一个 1~100 的整数，你来猜。猜大提示"大了"，猜小提示"小了"，猜对结束。

```python
import random
secret = random.randint(1, 100)      # 随机想一个 1~100 的整数
print("我心里想了一个 1~100 的数字，来猜！")
while True:                          # 不知道猜几次，用 while
    guess = int(input("你猜："))
    if guess > secret:
        print("大了")
    elif guess < secret:
        print("小了")
    else:
        print("猜对啦！就是", secret)
        break                        # 猜对了，结束循环
```

> ⚠️ 常见坑：`input()` 返回的是**字符串**，必须 `int()` 转成整数才能比大小。忘了转换，`"50" > secret` 会按字符串比较，结果完全不对。

> 💡 **进阶：循环里还能套循环（嵌套循环）**。比如打印 3 行、每行 2 颗星的方阵，就是外层循环管行、内层循环管列：
> ```python
> for i in range(3):        # 外层：3 行
>     for j in range(2):    # 内层：每行 2 颗星
>         print("*", end="")
>     print()               # 换行
> # 输出：**（3 行）
> ```
> 内层循环每执行一遍完整的，外层才走一步：总共 `3 × 2 = 6` 次内层体。记法：**外层走一步，内层走一圈**。

## 🔍 实战二：计数器——数一数有几个

统计是循环最经典的用法：**把一串东西挨个看一遍，数出符合条件的个数**。套路固定三步：**清零 → 遍历 → 满足条件加一**。

```python
text = "banana"
count = 0
for ch in text:              # 遍历字符串，ch 依次是每个字符
    if ch in "aeiou":        # ch 是不是元音字母（a/e/i/o/u）？
        count += 1
print(count)                 # 输出：3（banana 里有 3 个 a）
```

`in` 表示"**是否包含**"：`"a" in "aeiou"` 为 True。"数有几个"的题都是这套路。

## 🧠 实战三：先假设，再找反例

判断一个数是不是质数（只能被 1 和它本身整除，比如 17），思路：**从 2 试到 num-1，发现能整除的就不是质数**。

```python
num = 17
is_prime = True                  # 先假设它是质数
for i in range(2, num):          # 从 2 试到 16
    if num % i == 0:             # 发现能整除的
        is_prime = False         # 推翻假设
        break                    # 不用再试了，立刻退出
print(is_prime)                  # 输出：True（num 改成 18 则输出 False）
```

这个模式叫"**先假设，再找反例**"：先假设成立，循环里找到一个反例就推翻（`is_prime = False` + `break`）。判断类题目通用。

## 🌸 实战四：拆分数字 + 水仙花数

水仙花数是三位数，它的每一位数字的立方之和等于它自己：153 = 1³ + 5³ + 3³。拆数字用 `//` 和 `%`：`153 // 100` 得百位，`153 // 10 % 10` 得十位，`153 % 10` 得个位。然后让程序把 100~999 都拆一遍、验一遍：

```python
for num in range(100, 1000):
    bai = num // 100
    shi = num // 10 % 10
    ge = num % 10
    if bai ** 3 + shi ** 3 + ge ** 3 == num:
        print(num)
# 输出：153 / 370 / 371 / 407
```

漂亮在哪？**判断逻辑写在循环里**——循环负责"挨个试"，if 负责"验货"，900 个数眨眼查完。
