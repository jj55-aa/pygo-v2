# 循环结构——让程序学会"重复干活"

## 🔁 循环就是"自动复读机"

作业被罚抄 100 遍"我下次不迟到了"——你会抄到崩溃。但程序不会，**写一遍，让它自己重复**，这就是**循环结构**。打印 100 行文字、把全班 40 个同学的成绩加起来，都是循环的活。

Python 有两种循环，记一个口诀：
- **`for` 循环：数着来**——知道要循环几次，就数着次数来
- **`while` 循环：看着来**——不知道几次，条件满足就一直转

```python
for i in range(3):
    print("第", i, "次：你好")
# 输出：第 0 次：你好 / 第 1 次：你好 / 第 2 次：你好
```

## 🔢 for 循环 + range：数着来

"打印 3 次'你好'"用 `for` 循环，配 `range` 这个"发牌员"。`range(3)` 生成一串数 `0, 1, 2`（**从 0 开始，没有 3**），循环变量 `i` 依次变成这串数里的每一个，每变一次就执行一遍循环体。

```python
for i in range(3):
    print(i)        # 输出：0 / 1 / 2（每行一个）
```

`range` 有三种用法，核心规则就一句：**含头不含尾（左闭右开）**。
- `range(5)`：从 0 开始，共 5 个数 → 0 1 2 3 4
- `range(1, 5)`：从 1 开始，到 5 之前结束 → 1 2 3 4
- `range(1, 10, 2)`：从 1 开始，每步加 2 → 1 3 5 7 9

> ⚠️ 常见坑：`range(n)` 是"n 个名额"，从 0 数到 n-1，**没有 n 本身**。想打印 1、2、3，得写 `range(1, 4)`。

## ⏳ while 循环：看着来

不知道要循环几次，只知道"**条件成立就继续**"——用 `while`。比如角色掉血，只要血量大于 0 就继续挨打：

```python
hp = 100
while hp > 0:
    print("还有", hp, "滴血")
    hp -= 30           # 每回合掉 30 血
print("阵亡了")
# 输出：还有 100/70/40/10 滴血，最后"阵亡了"
```

执行流程：**先看条件** → 成立就执行循环体 → 执行完**再看条件** → 直到条件不成立才退出。

> ⚠️ **常见坑：死循环！** 如果循环体里忘了让 `hp` 变小，条件永远成立，程序就在里面转圈圈出不来，就像复读机**没装停止键**。万一真跑出死循环别慌：按 `Ctrl + C` 强制终止。**while 循环体里一定要有代码让条件"朝不成立的方向变化"**（让 `hp` 减少、让 `n` 加 1）。

## 🚪 break 和 continue：退场与跳步

循环本来要转完所有次数，但有时候**找到目标就不用再找了**。`break` 的意思是"**立刻走人**"——直接跳出整个循环；`continue` 是"**跳过这一轮，但循环继续**"。

```python
for i in range(1, 6):
    if i == 3:
        continue          # 跳过 3，循环继续
    print(i)              # 输出：1 / 2 / 4 / 5
```

> 💡 一句话分清：
> - `break` = **退场**：整个循环结束
> - `continue` = **跳步**：只跳过这一次，循环继续
