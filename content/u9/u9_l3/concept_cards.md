# 正则表达式：re 模块实战——文字迷宫终章

## 🔍 re.findall 与 re.finditer：把文本里所有宝藏都翻出来

迷宫墙上刻满符文。`re.findall` 就像带着放大镜把整面墙**从头到尾扫一遍**，把所有符合形状的符文都抄进一张清单（**列表**）；`re.finditer` 则像按顺序逐个端详——它每次递给你一个「符文样本」（**匹配对象**），你还能从样本里拆出分组。

**re.findall(模式, 文本)**：找**所有**匹配，返回**列表**（没有匹配返回空列表 `[]`）。
**re.finditer(模式, 文本)**：找**所有**匹配，返回**迭代对象**；用 `for` 循环逐个拿匹配对象 `m`，`m.group()` 取整段、`m.group(1)` 取第 1 组。

```python
import re
text = "电话 010-12345678，手机 13812345678"

# findall：全部匹配 → 列表
print(re.findall(r"\d+", text))
# ['010', '12345678', '13812345678']

# finditer：迭代对象，可配 group 取分组
for m in re.finditer(r"(\d{3})-(\d{8})", text):
    print(m.group(1), m.group(2))
# 010 12345678
```

> ⚠️ 易错点：① `findall` 的模式里一旦加了括号（分组），返回的就是**分组内容**的元组列表，整段匹配会被丢掉——只想取整段，就别加括号；② `finditer` 返回的**不是列表**，不能直接 `len()` 或按下标取，要先 `for` 循环或 `list()` 转一下。

## 🧹 re.sub：智能抹刀，一个模式刮平一片

迷宫管理员手里有把「智能抹刀」——不是一下一下擦单个字符，而是把一整段**符合模式的空白**刮平，糊成规规矩矩的一个空格。

**re.sub(模式, 替换成, 文本)**：把文本里所有匹配模式的地方整块替换，返回**新字符串**（原字符串不变）。
`\s` 匹配任意空白——空格、换行 `\n`、制表符 `\t` 都算；`\s+` 匹配「一段连续空白」。所以 `re.sub(r"\s+", " ", text)` 能把多个空格/换行压成一个空格，这是**清洗文本**最常用的一招：

```python
import re
text = "文字  迷宫  的  出口\n就在  前方"
clean = re.sub(r"\s+", " ", text)
print(clean)
# 文字 迷宫 的 出口 就在 前方
```

> ⚠️ 易错点：① 替换字符串里 `\1` 表示「第 1 组匹配到的内容」（引用分组），不是普通字符——`re.sub(r"(\d+)元", r"¥\1", "12元")` 得到 `¥12`；② `re.sub` **不修改原字符串**，结果要靠返回值接住（`clean = re.sub(...)`），不接就白换了；③ `\s` 不只是空格：换行、制表符也是空白，想「只压空格」才用 `" "` 字面量。

## ✂️ re.split：按「一类字符」切段

普通 `"字符串".split()` 只能按**固定字符**切；`re.split` 是一把「模式剪刀」——按**一类字符**切：遇到空格、逗号、分号……凡是符合模式的都是切口，把文本切成一段段**列表**。

**re.split(模式, 文本)**：按匹配模式的位置切分，返回**列表**。

```python
import re
text = "苹果，香蕉,橙子；西瓜"
parts = re.split(r"[，,;；]", text)
print(parts)
# ['苹果', '香蕉', '橙子', '西瓜']
```

> ⚠️ 易错点：① **模式里加了括号（分组），分隔符本身也会被保留进结果**——`re.split(r"(,)", "a,b")` 返回 `['a', ',', 'b']`，结果里多出了分隔符；想只留片段，就别加括号；② 字符串末尾是分隔符时，结果末尾会有一个**空串**片段（`"a,"` 切完是 `['a', '']`），这不是 bug，是切分规则的正常结果。

## 🚩 flags 与综合清洗：给正则加开关，把脏文本洗干净

flags 是正则机关上的「模式拨盘」——**re.IGNORECASE** 就是拨到「忽略大小写」那一档。它是**函数的参数**（第三个参数），不是刻在锁芯上的花纹（前缀）：

```python
import re
# re.IGNORECASE 是参数，不是正则字符串的一部分
print(re.findall(r"python", "Python PYTHON python", re.IGNORECASE))
# ['Python', 'PYTHON', 'python']——三种写法都被找出来，原样保留
```

**综合清洗流程**：面对一段脏文本，先整理、再提取——① 去掉空白行（strip 后为空的行不要）；② 把每行的多个空白压成单个空格；③ 最后再按需用 findall 提取数据：

```python
import re
text = """Python  入门   手册

  第1章  安装  Python

  第2章  字符串与正则
"""
# ① 去掉空白行
lines = [line for line in text.splitlines() if line.strip()]
# ② 每行的多个空白压成单个空格
clean = [re.sub(r"\s+", " ", line.strip()) for line in lines]
print("\n".join(clean))
# Python 入门 手册
# 第1章 安装 Python
# 第2章 字符串与正则
```

> ⚠️ 易错点：① **re.IGNORECASE 是 flags 参数，不是正则前缀**——`re.findall(r"IGNORECASE\d", text)` 只是在匹配字面量文本 "IGNORECASE"，跟忽略大小写毫无关系；② 不传 flags 时大小写必须完全一致，`"Python"` 匹配不到 `"python"`；③ 综合清洗要「先整理、再提取」：先 sub 压空白、去空白行，最后才 findall 提数据——顺序反了，脏格式会被一起带进结果。
