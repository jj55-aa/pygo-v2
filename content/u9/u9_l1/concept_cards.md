# 正则表达式：元字符

## 🗺️ 正则表达式：文字的「地图密码」

你站在文字迷宫的入口：一整面墙上刻满了密密麻麻的符文。你想找出墙上的**所有数字**——用眼睛一行行找？眼睛都要花。能不能像按图索骥一样，告诉迷宫"我要找长得像数字的东西"，让它一次全给你揪出来？

这就是**正则表达式**（Regular Expression，简称 regex）：一种**模式语言**——你不是描述"要找哪几个具体的字"，而是描述"要找**什么形状**的字符"，Python 就顺着这个模式在文本里**按图索骥**，把所有符合形状的内容一次捞出来。

对比一下"普通查找"和"正则查找"：

- 普通查找：`"手机" in text`、`text.find("手机")`——只能找**一字不差**的固定文字
- 正则查找：`re.findall(r"\d+", text)`——按**形状**找，数字、邮箱、手机号都能一次全捞

```python
import re
text = "电话：13812345678，邮编：100010"
print("电话" in text)              # True，普通查找：只能找固定文字
print(re.findall(r"\d+", text))    # ['13812345678', '100010']，正则查找：按模式全捞
```

> ⚠️ 新手最容易踩的坑：
> 1. 正则匹配的是**模式**（"像数字的一串"），不是固定文字——`in` 只能找它见过的那句话，正则能找它从没见过的新数据。
> 2. 用正则前必须先 `import re`，否则会报 `NameError: name 're' is not defined`。

## 🔢 三大元字符：\d \w \s

迷宫墙上的符文，看久了会发现它们就那么几种"基本刻法"：有数字、有字母、有空白缝隙。正则里用**元字符**（metacharacter）来代表"某一整类字符"——一个符号，顶一类字符。

| 元字符 | 匹配什么 | 例子 |
| --- | --- | --- |
| `\d` | 一个**数字**（0~9） | `re.findall(r"\d", "a1b2")` → `['1', '2']` |
| `\w` | 一个**字母 / 数字 / 下划线** | `re.findall(r"\w", "hi_9!")` → `['h', 'i', '_', '9']` |
| `\s` | 一个**空白**（空格、换行、Tab） | `re.findall(r"\s", "a b\nc")` → `[' ', '\n']` |

三个元字符合起来念：**\d 是数字（digit）、\w 是单词字符（word）、\s 是空白（space）**。学会了它们，你就有了第一批"看图识字"的符文能力。

```python
import re
print(re.findall(r"\d", "a1 b2 c3"))     # ['1', '2', '3']
print(re.findall(r"\w", "hi_9!"))        # ['h', 'i', '_', '9']
print(re.findall(r"\s", "a b\nc"))       # [' ', '\n']
```

> ⚠️ 新手最容易踩的坑：
> 1. 每个元字符**只占一个位置**：`\d` 只匹配**一位**数字。想匹配一整串数字（比如 13812345678），要用 `\d+`——`+` 是"量词"，表示"至少 1 个"，`\d+` 就是"连续的一串数字"（下一课会系统学量词）。
> 2. `\w` 是"字母/数字/下划线"三合一；注意 Python 3 里它**默认还认中文**（Unicode 字符，实测 `re.findall(r"\w", "你好a1_!")` → `['你', '好', 'a', '1', '_']`）。想严格只匹配英文字母/数字/下划线，用字符类 `[A-Za-z0-9_]`（本课后面就讲 `[ ]` 字符类）。

## 🎯 字符类 [ ] 与 . ^ $

光有三大元字符还不够。迷宫墙上有些符文是"点菜式"的：我只要**小写字母**，或者只要**0~9**。这时用**字符类**——用方括号 `[ ]` 把"这一位允许出现哪些字符"列出来，精确到你想点的菜：

| 写法 | 含义 | 例子 |
| --- | --- | --- |
| `[0-9]` | 0~9 任意一个（等价于 `\d`） | `re.findall(r"[0-9]", "a1b2")` → `['1', '2']` |
| `[a-z]` | 小写字母任意一个 | `re.findall(r"[a-z]", "Hello")` → `['e', 'l', 'l', 'o']` |
| `[aeiou]` | a、e、i、o、u 中任意一个 | `re.findall(r"[aeiou]", "hello")` → `['e', 'o']` |

再认识三个"位置型"符文：

- `.`（点）：匹配**除换行外**的任意一个字符——万能符文
- `^`（脱字符）：只认**字符串开头**
- `$`（美元符）：只认**字符串结尾**

```python
import re
print(re.findall(r"[0-9]", "a1b2"))      # ['1', '2']，等价于 \d
print(re.findall(r"[a-z]", "Hello"))     # ['e', 'l', 'l', 'o']，大写 H 不匹配
print(re.findall(r"^a", "abc a"))        # ['a']，只认开头的 a
print(re.findall(r"a$", "abc a"))        # ['a']，只认结尾的 a
print(re.findall(r".", "ab\ncd"))        # ['a', 'b', 'c', 'd']，换行被跳过
```

> ⚠️ 新手最容易踩的坑：
> 1. `.` **不匹配换行**：文本里夹着 `\n` 时，`.` 会跳过它——想连换行一起匹配有专门的写法（`re.DOTALL`，后面课再讲）。
> 2. 字符类 `[ ]` 里的每一个也**只占一个位置**：`[0-9]` 和 `\d` 完全等价，都只匹配一位数字。
> 3. `^` 在 `[ ]` **里面**含义完全不同（是"取反"，如 `[^0-9]` 表示"非数字"）——别和"开头"搞混。

## 📡 re.findall 与原始字符串 r"..."

符文认出来了，谁来"扫墙"？Python 的 `re` 模块里，**`re.findall(模式, 文本)`** 就是那台扫描仪：拿着你给的模式，把整段文本从头扫到尾，**所有**匹配的片段收进一个**列表**还给你。一个都没扫到？返回空列表 `[]`，不报错。

正则字符串前面那个不起眼的 **`r`** 是什么？它表示**原始字符串**（raw string）：告诉 Python "反斜杠别乱处理，原样交给 re 模块"。Python 会**抢先**处理字符串里的反斜杠——`"\d"` 这种写法会触发 `invalid escape sequence` 告警（Python 3.12+ 直接显示 SyntaxWarning，未来版本还可能升级成报错）；更危险的是 `"\b"`：Python 先把它转成**退格符**，你写的是正则里的「单词边界」，匹配的却是退格字符，结果完全跑偏。**写正则永远加 `r`**，这是保命法则第一条。

```python
import re
text = "门牌 101 号，密码 2024"
nums = re.findall(r"\d+", text)   # r 前缀：保护 \d 里的反斜杠不被转义
print(nums)                        # ['101', '2024']，返回的是列表
print(len(nums))                   # 2，列表就能用 len 数个数
```

> ⚠️ 新手最容易踩的坑：
> 1. **忘加 `r`**：`"\d"`、`"\w"` 这类反斜杠写法会触发 `invalid escape sequence` 告警（Python 3.12+ 直接显示 SyntaxWarning，未来版本还可能升级成报错）；`"\b"` 更糟——Python 会把它转成**退格符**，你以为是「单词边界」，匹配的却是退格字符。正则字符串一律写 `r"..."`。
> 2. `findall` 返回的是**列表**（匹配不上的时候是空列表 `[]`），不是字符串、也不是 None——别拿它直接和字符串比较。
> 3. 列表里装的是**字符串**：`['101', '2024']` 里是 `"101"`、`"2024"`，想当数字用要先 `int()` 转换。
