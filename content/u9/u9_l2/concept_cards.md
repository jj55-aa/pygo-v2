# 正则表达式：量词与分组

## 🎚️ 量词四兄弟：给「出现几次」装上遥控器

上一课学过：元字符 `\d`、`\w` **只占一个位置**——`\d` 只能匹配一位数字。那要匹配"第 1 名"和"第 12 名"这种位数不定的数字怎么办？难道写两遍 `\d`？不用！**量词（Quantifier）** 就是装在元字符后面的"遥控器"，专门控制它**出现几次**。

迷宫里有四位操作员，记住它们各自的口头禅：

| 量词 | 含义 | 口头禅 | 例子 |
| --- | --- | --- | --- |
| `*` | 0 次或多次 | 「可有可无，有也不嫌多」 | `ab*c` 能匹配 `ac`、`abc`、`abbc` |
| `+` | 1 次或多次 | 「至少要有一个」 | `第\d+名` 能匹配 `第1名`、`第12名` |
| `?` | 0 次或 1 次 | 「最多来一个」 | `colou?r` 能匹配 `color`、`colour` |
| `{n,m}` | n 到 m 次 | 「就要这么多」 | `\d{2,4}` 匹配 2~4 位数字 |

```python
import re
print(re.findall(r"\d{2,4}", "1 12 123 1234 12345"))   # ['12', '123', '1234', '1234']
print(re.findall(r"第\d+名", "第1名 第12名"))           # ['第1名', '第12名']
print(re.findall(r"colou?r", "color colour"))          # ['color', 'colour']
print(re.findall(r"ab*c", "ac abc abbc"))              # ['ac', 'abc', 'abbc']
```

> ⚠️ 新手最容易踩的坑：
> 1. **`*` 和 `+` 的区别就差在"0 次"**：`\d+` 至少要一个数字（`"abc"` 里一个都匹配不到，返回 `[]`）；而 `\d*` 连 0 个数字也算匹配——所以它能"匹配到"空位置，结果里会冒出空字符串 `''`。
> 2. `?` 有两种身份：跟在字符后面是量词（0 次或 1 次）；跟在 `*` `+` 后面是"惰性开关"（下一张卡讲）。
> 3. `{n,m}` 里的逗号是**英文逗号**，别用中文的 `，`。

## 🐍 贪婪 vs 惰性：贪吃蛇还是小鸟吃米？

现在你来到迷宫的一条美食长廊：地上一排米粒。**贪吃蛇**（贪婪匹配 `.*`）张开大嘴——能吃到多少吃多少，**一直吃到最后一个符合条件的才停**；**小鸟**（惰性匹配 `.*?`）呢？**啄到第一粒米就停**，绝不贪心。

Python 里所有量词（`*` `+` `?` `{n,m}`）**默认都是贪婪的**，想变"小鸟"，就在量词后面再加一个 `?`：`.*` 变 `.*?`、`+` 变 `+?`。

```python
import re
html = "<b>甲</b>和<b>乙</b>"
print(re.findall(r"<b>.*</b>", html))    # ['<b>甲</b>和<b>乙</b>']  贪吃蛇：吞到最后一个 </b>
print(re.findall(r"<b>.*?</b>", html))   # ['<b>甲</b>', '<b>乙</b>'] 小鸟：遇到第一个 </b> 就停
```

> ⚠️ 新手最容易踩的坑：
> 1. 用 `.*` 从文本里抠数据经常"吃过头"：明明只要两个 `<b>` 标签，它一口气吞成一大串。**提取内容默认用 `.*?`**。
> 2. `.*?` 里的 `?` 不是"0 次或 1 次"的量词，它是**惰性开关**——作用是让前面的 `*`"尽量少吃"。

## 📦 分组 ()：把模式打包，还能单独拆出来

迷宫墙上有一段联系方式：`电话010-12345678`。你要的不是整串，而是**区号 010** 和**号码 12345678**。正则的**分组**就是一根"打包绳"：用括号 `()` 把一段模式捆成一包，之后可以**按编号把包里的东西单独掏出来**。

掏东西的接口是 `m.group(编号)`：

```python
import re
m = re.search(r"(\d{3})-(\d{8})", "电话010-12345678")
print(m.group(1))     # 010          第 1 个括号
print(m.group(2))     # 12345678     第 2 个括号
print(m.group(0))     # 010-12345678 整个匹配
print(re.findall(r"(\d{3})-(\d{8})", "电话010-12345678"))   # [('010', '12345678')]
```

> ⚠️ 新手最容易踩的坑：
> 1. **`group(1)` 从 1 开始编号，但 `group(0)` 不是"第 0 个括号"——它是整个匹配**！`m.group(0)` 完全合法，返回 `010-12345678`。以为它不存在、一调用就报错，是头号误解。
> 2. **`findall` 遇到分组就"变心"**：不带括号时返回匹配串列表；带了括号，返回的是**每组内容的元组**：`[('010', '12345678')]`。
> 3. 只有被 `()` 包起来的部分才叫分组。想取 `group(1)`，必须先写一对括号。

## 🧰 实战组合：\d+、\w+ 与密码提取

量词 + 元字符 + 分组，三件套拼起来就是完整的"提取咒语"。迷宫里的任务来了：从一行字里把**数字串**、**单词**、**密码**分别抠出来。

```python
import re
text = "迷宫墙上写着：密码：abc123，暗号 42，口令 xyz"
print(re.findall(r"\d+", text))                      # ['123', '42']  所有数字串
print(re.findall(r"[A-Za-z0-9_]+", "hello world!"))  # ['hello', 'world'] 英文单词
m = re.search(r"密码[:：]\s*(\w+)", text)
print(m.group(1))                                    # abc123  分组提取密码
```

拆解这条最常用的"密码咒语" `r"密码[:：]\s*(\w+)"`：
- `密码` 先匹配两个汉字，把位置钉死
- `[:：]` 字符类：中文冒号 `：` 和英文冒号 `:` **都能匹配**
- `\s*` 吃掉"冒号和密码之间"可能存在的空格（0 个或多个）
- `(\w+)` 分组：抓一串字母数字下划线，就是密码本体

> ⚠️ 新手最容易踩的坑：
> 1. **`\w` 默认还认中文**（Unicode 字符）：`\w+` 在 `"hello 迷宫"` 里会连 `迷宫` 一起匹配出来。想要"纯英文单词"，用 `[A-Za-z0-9_]+`。
> 2. `re.search` **只返回第一个匹配**；想一次抓全部，用 `re.findall`。
> 3. 匹配失败时 `re.search` 返回 `None`，直接 `m.group(1)` 会报 `AttributeError`——先用 `if m:` 判断一下更稳妥。
