# 变量——给数据贴个标签

## 🧺 变量就是贴了标签的盒子

想象你走进水果店，店员递给你一个篮子：往里放苹果、放香蕉、放橘子，想放什么放什么。**篮子本身不变，变的是里面的东西。**

Python 里的**变量**就是这个篮子——它是一块用来存数据的内存空间，你可以往里面放数字、放文字、放真假值，然后给它贴个标签（变量名）。以后想用里面的数据，喊一声名字就行。

```python
box = "苹果"    # 一个叫 box 的盒子，装了 "苹果"
box = "香蕉"    # 换货！box 现在装的是 "香蕉"
print(box)      # 输出：香蕉
```

注意：第二行执行后，原来的 "苹果" 就被覆盖了。**变量名不变，值可以变**——这正是"变量"二字的由来。

## ✍️ 赋值：把数据装进盒子

用 **`=`（等号）给变量赋值**：

```python
name = "小明"    # 字符串必须加引号
age = 18         # 数字不用加引号
score = 92.5     # 小数（浮点数）
```

> ⚠️ 新手最容易踩的坑：
> 1. **字符串必须加引号**。写 `name = 小明` 会直接报错——Python 会把"小明"当成另一个变量的名字去找。
> 2. 赋值要**从右往左**理解：把右边的值，装进左边的变量。

## 📦 常见的数据类型

| 类型 | 名字 | 例子 |
| --- | --- | --- |
| `int` | 整型（整数） | `age = 18` |
| `float` | 浮点型（小数） | `score = 92.5` |
| `str` | 字符串（文本） | `name = "小明"` |
| `bool` | 布尔型（真假） | `is_student = True` |

想知道一个变量装的是什么类型？用 `type()` 函数：

```python
a = 100
b = 12.5
c = "hello"
d = True
print(type(a))   # <class 'int'>
print(type(b))   # <class 'float'>
print(type(c))   # <class 'str'>
print(type(d))   # <class 'bool'>
```

## 🏷️ 变量命名规则（重点！）

起名有**硬性规定**，违反了直接报错：

- ✅ 只能由**字母、数字、下划线**组成，**数字不能开头**：`name_1` 合法，`1_name` 报错
- ✅ **大小写敏感**：`Name` 和 `name` 是两个不同的变量
- ✅ 不能和 Python **关键字**重名（`if`、`for`、`while`、`True`……这些词有特殊使命）

**好习惯**（不强制，但强烈建议）：

- **见名知意**：`age` 比 `a` 好，`student_count` 比 `sc` 好
- 多个单词用**下划线**连接：`user_name`、`total_score`

```python
# 好的变量名
user_name = "小明"
total_score = 95

# 差劲的变量名（能跑，但没人看得懂）
a = "小明"
ts = 95
```
