# 第一个程序——把话说给电脑听

## 🐍 Python 是什么？

Python 是一门**编程语言**，常年霸榜"最受欢迎语言"第一名。它的名字跟蛇没关系——是荷兰人吉多·范罗苏姆（Guido van Rossum）为了致敬他喜欢的英国喜剧团 **Monty Python** 起的。

Python 最大的特点就一个字：**简单**。它的代码读起来像英语句子，很多新手的第一门编程语言就是它。

```python
# 其他语言可能要写 5 行，Python 一行搞定：
print("你好，世界！")
```

## 🛠️ Python 能干什么？

别小看这门"简单"的语言，它几乎无所不能：

| 领域 | 例子 |
| --- | --- |
| 🕷️ 网络爬虫 | 自动抓取网页数据 |
| 📊 数据分析 | 处理 Excel、统计报表 |
| 🤖 人工智能 | 训练 AI 模型、图像识别 |
| 🌐 Web 开发 | 搭建网站、小程序后端 |
| 📁 自动化办公 | 批量改名、自动整理文件 |
| 🎮 小游戏 | 用 Pygame 写游戏 |

> 但 Python 做不到一件事：**直接改硬件**（比如改主板 BIOS）——它专注在软件世界。

## 🚀 怎么写和运行 Python 代码？

**Python 代码都写在 `.py` 文件里**，然后用"解释器"运行——就像把菜谱（代码）交给厨师（解释器）做菜。

那在哪写代码？答案是 **IDE**——一款专门用来写代码的软件，集成了写代码、运行、调试等功能。

**PyCharm 是最流行的 Python IDE**，很多 Python 开发者天天用它：

- ✍️ 写代码时有自动补全、语法提示
- ▶️ 点一下按钮就能运行你的 `.py` 文件
- 🐞 出错了能断点调试、一步步看代码怎么走

> 💡 **在我们软件里，你完全不用安装这些**：界面里内置了一个轻量 IDE（代码编辑器），左边写代码、右边看运行结果、点"运行"就判题。打开就能学，环境的事以后再操心。等以后做真实项目，再去装 PyCharm 就行。

## 📢 print：电脑的"复读机"

`print` 是你用的**第一个函数**，作用就一个：**把内容打印到屏幕上**。它就像个复读机，你说什么它打印什么。

```python
print("你好，世界！")       # 打印文字（要加引号）
print(1 + 2)              # 打印算式结果（先算出 3）
print("我的年龄", 18)      # 一次打印多个值（逗号隔开，自动加空格）
```

> ⚠️ **新手最容易踩的坑——标点**：
> 1. `print` 后面**必须有括号**：写 `print "你好"`（没括号）会直接报错
> 2. 文字**必须用引号**包起来：`print(你好)` 报错；引号要配对（左单右双也不行）
> 3. 逗号、括号、引号**只认英文半角**：中文的 `（ ）`、`，`、`“ ”` 当代码符号用会报 `SyntaxError`
>
> 一句话总结：写代码只用英文标点 `( )` `" "` `' '` `,`，中文标点只能出现在被引号包住的文字里。
