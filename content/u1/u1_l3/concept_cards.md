# 数字与字符串——让 Python 帮你算账

## 🧮 Python 就是你的计算器

打开 Python 直接输入算式，它立刻给你答案：

```python
print(10 + 3)     # 13
print(10 - 3)     # 7
print(10 * 3)     # 30
print(10 / 3)     # 3.3333333333333335
```

注意两个和数学课不一样的写法：**乘号用 `*`**（键盘没有 ×）、**除号用 `/`**（键盘没有 ÷）。

> ⚠️ 一个容易忽略的细节：**两个整数相除，结果也是浮点数**！`print(10 / 2)` 输出 `5.0` 而不是 `5`。

## ➗ 三个"隐藏高手"运算符

除了 `+ - * /`，还有三个非常常用的：

```python
print(10 // 3)    # 整除：只取商的整数部分 → 3
print(10 % 3)     # 取余：只取余数 → 1
print(2 ** 3)     # 幂运算：2 的 3 次方 → 8
```

回忆小学除法：**10 ÷ 3 = 商 3 余 1**。`//` 拿商，`%` 拿余数。

> 💡 取余 `%` 特别常用：判断奇偶（`x % 2` 是 1 就是奇数）、判断能不能整除。

还有一组"边算边存"的简写：

```python
count = 0
count += 1        # 等价于 count = count + 1
count *= 3        # 等价于 count = count * 3 → 3
print(count)      # 3
```

## 🔤 字符串：一串串起来的珠子

**字符串（str）**就是一串**按顺序排列的字符**，用引号包起来：

```python
s = "hello"
print(s[0])       # h，第一个字符
print(len(s))     # 5，一共 5 颗珠子
print("Py" + "thon")   # Python，+ 号拼接字符串
print("hi" * 3)   # hihihi，字符串也能乘
```

> ⚠️ 注意：**字符串用 `+` 拼接**，但 `"1" + 1` 会报错——字符串和数字不能直接加！数字要先 `str()` 转成字符串，或字符串先 `int()` 转成数字。

## 🔠 字符串的魔法方法

字符串自带很多"方法"（功能），先认识两个好玩的：

```python
print("hello".upper())    # HELLO，全部大写
print("HELLO".lower())    # hello，全部小写
print("123".isdigit())    # True，全是数字
```

> ⚠️ **这些方法不会改原字符串**，而是返回一个新的（字符串不可变）。想用结果要存下来：`s = s.upper()`。

**数字 ↔ 字符串转换**（input() 拿到的总是字符串）：

```python
age = int("18")       # 字符串 → 整数：18
price = str(3.5)      # 数字 → 字符串："3.5"
print(age + 1)        # 19，转完就能算数了
```
