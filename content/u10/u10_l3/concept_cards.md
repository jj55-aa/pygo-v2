# 图像处理——给车间装上"眼睛"

## 🖼️ 图像就是像素矩阵：一张"数字画布"

想象自动化车间的墙上挂着一张巨大的**数字画布**，画布被切成了密密麻麻的小方格。把一张照片无限放大，你也会看到同样的小方格——它们就是**像素（Pixel）**，图像的最小单位。

**图像本质上就是一个二维矩阵（表格）：宽 × 高 个像素，每个像素记录一个颜色。** 所谓"处理图像"，就是"把这张表格读进来 → 修改里面的像素值 → 再输出"。比如一张 100×80 的图，就是 100×80 = 8000 个小格子，排成 80 行、每行 100 个。

在判题环境里，我们用**二维列表**模拟这张数字画布——每个数字代表一个像素的"亮度"（0 最暗，255 最亮）：

```python
# 一张 3×3 的灰度小图：9 个像素，3 行 3 列
img = [
    [10, 200, 50],
    [80, 255, 30],
    [120, 40, 210],
]
print(len(img), "行 x", len(img[0]), "列")   # 3 行 x 3 列
print("左上角像素亮度:", img[0][0])           # 10
```

> ⚠️ 新手最容易踩的坑：
> 1. **尺寸是"宽 × 高"**：100×80 的图有 8000 个像素，不是 180 个（那是宽 + 高）！
> 2. 二维列表里 `img[i][j]`：第一个下标 `i` 是**行**（从上往下数），第二个 `j` 是**列**（从左往右数）。

## 🎨 RGB 三原色：一个像素 = 三个数字

每个像素的颜色不是画出来的，而是**用三个数字调出来的**。计算机用 **RGB 三原色** 表示颜色：**R（Red 红）、G（Green 绿）、B（Blue 蓝）**，三束光按不同强度混合，就能调出人眼看到的所有颜色。

- 每个通道的取值范围是 **0 ~ 255**（共 256 级）
- `(0, 0, 0)` = 黑色（什么都不亮）；`(255, 255, 255)` = 白色（全亮）
- `(255, 0, 0)` = 纯红；`(0, 255, 0)` = 纯绿；`(0, 0, 255)` = 纯蓝

```python
# 一个像素用三元组 (R, G, B) 表示
pixel_red = (255, 0, 0)
pixel_black = (0, 0, 0)
print("这个像素是", pixel_red[0], "份红、", pixel_red[1], "份绿、", pixel_red[2], "份蓝")
```

> ⚠️ 新手最容易踩的坑：
> 1. **每通道是 0~255，不是 0~100**：255 是 2⁸-1，一个字节（8 位二进制）能表示的最大值。
> 2. 别把顺序搞混：是 **R-G-B（红绿蓝）**，不是 GBR。`(0, 255, 0)` 是绿色，不是红色。

## 🧰 Pillow 库能干啥：车间的"图像工具箱"

真实世界里处理图像，Python 最常用的是 **Pillow 库**（也叫 PIL，Python Imaging Library 的继任者）。它就像挂在车间墙上的一排**工具箱**，图像处理的常用活儿随取随用：

- **打开与查看**：`Image.open("照片.jpg")` 打开图片；`img.size` 得到 `(宽, 高)`（单位像素）；`img.mode` 看颜色模式（RGB 彩色 / L 灰度）
- **裁剪与缩放**：`img.crop((左, 上, 右, 下))` 裁出矩形区域；`img.resize((宽, 高))` 改尺寸
- **滤镜与转换**：`img.convert("L")` 一键转黑白灰；`img.rotate(90)` 旋转
- **现实场景**：批量压缩图片、给照片加水印、PNG 转 JPG 格式转换……循环 + Pillow，全自动搞定

```python
from PIL import Image   # 需要先安装：pip install Pillow

img = Image.open("照片.jpg")
print(img.size)               # (1920, 1080)：1920 宽 x 1080 高
img.crop((100, 50, 400, 350)).save("裁剪后.png")   # 裁剪并保存新图
img.convert("L").save("黑白版.jpg")                # 转成灰度图
```

> ⚠️ 新手最容易踩的坑：
> 1. **Pillow 要自己装**：`from PIL import Image` 之前要先 `pip install Pillow`，否则报 `ModuleNotFoundError`。
> 2. `crop` 是**四个坐标** `(左, 上, 右, 下)`，不是 `(x, y, 宽, 高)`；`resize` 是**宽在前、高在后**，跟"行、列"的习惯正好相反。

## 💻 用列表模拟像素：判题环境也能处理图像

Pillow 再强大，我们的**判题环境（Pyodide）里没有装 Pillow**，`from PIL import Image` 会直接报错。换个思路：**用二维列表模拟像素矩阵**，图像处理就退化成"两层循环遍历矩阵、改每个数字"——反色、亮度调整这些基础操作照样能完成！

- **反色（负片效果）**：每个像素 x → `255 - x`
- **亮度增强**：每个像素 x → `x + 50`，超过 255 就**封顶 255**
- **遍历套路**：外层循环走行，内层循环走列，**用下标 `img[i][j]` 写回**才改得到原矩阵

```python
img = [
    [10, 200],
    [80, 255],
]
# 反色：每个像素 255 - x
for i in range(len(img)):
    for j in range(len(img[i])):
        img[i][j] = 255 - img[i][j]
for row in img:
    print(*row)      # 输出：245 55 / 175 0
```

> ⚠️ 新手最容易踩的坑：
> 1. **反色是 `255 - 原值`，不是 `原值 + 255`**：加 255 数值就超出 0~255 的范围了。
> 2. `for pixel in row:` 循环里改 `pixel` 只是改了**临时变量**，改不回列表！必须用下标 `img[i][j] = ...` 写回。
> 3. 亮度增强超过 255 要**封顶**：`min(x + 50, 255)`，不然像素值就"越界"了。
