# 邮件自动化——让 Python 替你发信

## ✉️ 一封邮件 = 四个部件（收件人 / 主题 / 正文 / 附件）

给客户发周报，先得把「信」写好。一封邮件有四个部件，就像一封信要备齐的四个部分：

- **收件人（To）**：信寄给谁——客户的邮箱地址，如 `boss@example.com`
- **主题（Subject）**：信封上的一句话摘要——别人一眼看到「周报」，就知道这封信是干嘛的
- **正文（body）**：信纸上的内容——这周干了什么、有什么结论
- **附件（attachment）**：夹在信里的小册子——Excel 报表、图片等文件

程序里组织一封邮件，就是把**这四样数据组装起来**。本课的练习环境不能真发信，我们就用**字符串、字典、列表**把邮件数据模拟出来；真实环境里，组装好的数据会被交给发送模块。

```python
# 模拟一封邮件：用字典把四个部件装好（判题环境练习用）
mail = {
    "收件人": "boss@example.com",
    "主题": "周报",
    "正文": "本周 3 个任务全部完成，详见附件。",
    "附件": ["周报.xlsx", "统计图.png"],
}
print("收件人：", mail["收件人"])
print("主题：", mail["主题"])
print("附件数：", len(mail["附件"]))
```

> ⚠️ 新手最容易踩的坑：
> 1. **收件人地址别写错**——写错就发到别人家（或直接被退信），一个字母都不能差。
> 2. **主题别留空**——没有主题的邮件最容易进垃圾箱，客户根本看不见。
> 3. 中文正文要配上 `utf-8` 编码，否则发出去会乱码。

## 🏣 发信三要素：SMTP 服务器 + 授权码 + 收件人

信写好了，怎么到客户手里？靠「电子邮局」——**SMTP 服务器**（SMTP = Simple Mail Transfer Protocol，简单邮件传输协议）。你负责把信交给邮局，邮局负责送到客户的邮箱。

要把信「交给邮局」，程序员手里必须备齐三样（**发信三要素**）：

| 要素 | 是什么 | 比喻 |
| --- | --- | --- |
| SMTP 服务器地址 | 邮局在哪：如 QQ 邮箱 `smtp.qq.com` | 邮局的门牌号 |
| 账号 + 授权码 | 你是谁 + 托运凭证 | 身份证 + 托运专用凭证 |
| 收件人地址 | 信送给谁 | 信封上的地址 |

⚠️ 关键：**授权码 ≠ 登录密码**。登录网页邮箱用的是密码，SMTP 发信用的是**授权码**——去邮箱设置里开启「SMTP 服务」，系统会生成一串专属授权码。打个比方：密码是「家门钥匙」，授权码是「邮局托运凭证」——你拿家门钥匙进邮局没用，必须出示托运凭证。

```python
# 发信三要素（真实环境示例：换成你自己的邮箱和授权码）
SMTP_SERVER = "smtp.qq.com"   # ① 邮局地址：QQ 邮箱
ACCOUNT = "me@qq.com"          # ② 邮箱账号
AUTH_CODE = "这里填授权码"     # ② 授权码（不是登录密码！）
RECEIVER = "boss@example.com"  # ③ 收件人地址
```

> ⚠️ 新手最容易踩的坑：
> 1. **用登录密码登录 SMTP 一定失败**——必须去邮箱设置里开启 SMTP 服务，拿到授权码。
> 2. **SMTP 服务器地址要写对**——QQ 是 `smtp.qq.com`、163 是 `smtp.163.com`，写错连不上邮局。
> 3. 授权码等于你账号的「钥匙」，**别写死在代码里**（代码会发给人、传到网上），用环境变量或配置文件存。

## 📮 smtplib 发信流程：写信 + 投递

Python 发邮件是两个标准库的分工合作：

- **email 模块**负责「写信」：用 `MIMEText` 组织正文/主题/收件人（MIME 是一种邮件内容的组织格式）
- **smtplib 模块**负责「投递」：连接 SMTP 服务器 → 登录 → 发送 → 关闭

真实环境的固定流程四步：`SMTP_SSL(地址, 465)` 连接邮局 → `login(账号, 授权码)` 出示凭证 → `send_message(msg)` 投信 → `quit()` 挂断。

```python
# ==== 真实环境示例：需要真实邮箱 + 授权码，判题环境不能真发信，别在这里运行 ====
import smtplib
from email.mime.text import MIMEText

# ① email 模块「写信」
msg = MIMEText("你好，这是 Python 自动发的邮件！", "plain", "utf-8")  # 正文，utf-8 防乱码
msg["Subject"] = "周报"                # 主题
msg["From"] = "me@qq.com"              # 发件人
msg["To"] = "boss@example.com"         # 收件人

# ② smtplib 模块「投递」
smtp = smtplib.SMTP_SSL("smtp.qq.com", 465)   # 连接邮局（SSL 加密）
smtp.login("me@qq.com", "授权码")              # 登录（用授权码！）
smtp.send_message(msg)                         # 发送
smtp.quit()                                    # 关闭连接
```

**本课的练习环境（Pyodide）没有真实发信能力，也绝不能真发邮件**——所以发信流程我们「概念照讲」，练习时用字符串/列表**模拟邮件数据组装**：把「收件人、主题、正文」组织好、打印出来，就当作发信成功。真实项目里，把「打印」换成上面的 `send_message`，就是真的发信了。

> ⚠️ 新手最容易踩的坑：
> 1. **判题环境不能真发信**——练习一律用模拟（打印输出代替真实发送），别指望在 PyGo 里把邮件发给别人。
> 2. 登录**用授权码不是密码**；服务器地址/端口写错（QQ 用 465）也会连不上。
> 3. 带附件要用 `MIMEMultipart` 当「信封」、`attach()` 把正文和附件都塞进去——附件不是直接写进 MIMEText 的。

## 🔁 批量发信：循环 + 模板

车间要给 50 位客户发周报，手动一封封复制粘贴，发完手指都抽筋。**批量发信 = 模板 + 循环**：

- **模板**：一封邮件的格式是固定的，只有收件人、称呼、数据不同——用 f-string 把不同的部分填进去
- **循环**：`for` 遍历收件人列表，一圈一封，自动生成

```python
# 模拟批量发信（判题环境：用 print 代替真实发送）
recipients = ["boss@example.com", "alice@example.com", "bob@example.com"]
for to in recipients:
    title = f"收件人：{to}，主题：周报"   # 模板：按收件人生成标题
    print(title)
```

运行后会按每个收件人打印一行，形如：`收件人：boss@example.com，主题：周报`——三个收件人就是三行。

现实场景：**批量发周报**、**定时提醒**（到点自动发）、**群发成绩单/活动通知**——把循环里的 `print` 换成 `smtp.send_message(msg)`，就是真正的批量发信。这也是互联网上那些「自动发的邮件」的来源。

> ⚠️ 新手最容易踩的坑：
> 1. **模板里别漏了 f-string 的花括号 `{}`**——漏了不报错，但所有人收到的是同一封没有名字的「哑巴邮件」。
> 2. 循环里**每一轮都要重新组装邮件**（收件人字段跟着变），别把上一轮的收件人带到下一封。
> 3. 真实批量发送前，**先发 1~2 封测试**（发给自己），确认格式无误再发全量——发错了就是 50 封道歉信。
