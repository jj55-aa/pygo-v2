# 解析 HTML——从网页骨架里挖数据

## 🕸️ HTML 是网页的骨架

想象蜘蛛峡谷里那张巨大的蛛网：**每一条丝线都不是凭空悬着的，而是由一根根"骨架"撑起来的**。网页也一样——你看到的文字、图片、链接，背后都有一份叫 **HTML** 的"施工图纸"，浏览器就是照着它把页面搭出来的。

而爬虫用 requests 拿到的，**不是渲染好的页面，正是这份图纸**——一堆带着尖括号的标签字符串。想看穿它，先认识标签的骨架结构：

```html
<html>
  <body>
    <div>
      <p>峡谷日报</p>
      <a href="/news/1">情报一</a>
    </div>
  </body>
</html>
```

- **标签成对出现**：开始标签 `<p>` + 结束标签 `</p>`（结束标签多一个斜杠 `/`），**要提取的数据就夹在两者中间**
- **层层嵌套**：`<html>` 套 `<body>`，`<body>` 套 `<div>`……就像俄罗斯套娃、蛛网的一层层——**先开的标签要后关**
- 像 `<a href="/news/1">` 这种写法：`<a>` 是标签名，`href="/news/1"` 是**属性**

> ⚠️ 新手最容易踩的坑：
> 1. 标签**必须成对**：写了 `<p>` 就要有 `</p>`，结束标签里那个斜杠 `/` 千万别漏
> 2. 嵌套要**先开先关、后开后关**：`<div><p>文字</p></div>` 才对，交叉闭合（`<div><p></div></p>`）是错的
> 3. 尖括号要用英文 `<>`，写成中文书名号 `《》` 就废了

## 🏷️ 常用标签与属性：认一认峡谷的建材

蜘蛛峡谷的建材库里，常用的"骨架件"就几种：

| 标签 | 作用 | 例子 |
| --- | --- | --- |
| `<h1>` | 大标题（h1~h6 依次变小） | `<h1>峡谷情报网</h1>` |
| `<p>` | 段落文字 | `<p>今日要闻</p>` |
| `<a>` | 超链接，点击跳转 | `<a href="/news/1">阅读全文</a>` |
| `<div>` | 块容器，圈出一块区域 | `<div class="channel">…</div>` |

**属性**写在开始标签里，写法是 `属性名="属性值"`，最常见三个：

- `href="网址"`：`<a>` 标签跳转的目标地址
- `class="分类名"`：给标签贴分类标签，**同一类数据通常 class 相同**——抓这一个 class 就能批量抓同一类数据
- `id="唯一名"`：页面上独一无二的标识

```html
<h1>蜘蛛峡谷情报网</h1>
<div class="channel">
  <p>今日要闻：峡谷深处发现新蛛网。</p>
  <a href="/news/1">阅读全文</a>
</div>
```

> ⚠️ 新手最容易踩的坑：
> 1. **属性值必须用引号括起来**（英文引号）：`href="/news/1"` 才对，`href=/news/1` 不标准
> 2. `href` 是**属性**不是标签——跳转靠的是 `<a>` 标签 + `href` 属性
> 3. 标签名/属性名**拼错一个字**（比如 `href` 写成 `herf`）就抓不到目标

## 🍲 bs4：HTML 解析神器（真实环境）

爬虫的完整流程就两步：

1. **第一步（u11_l1 学过）**：用 requests 向服务器要网页，拿到 **HTML 字符串**
2. **第二步（本课）**：**解析这份 HTML，把想要的数据提取出来**

问题来了：HTML 字符串里混着密密麻麻的标签，怎么快速找到 `<a>` 链接、按 class 定位数据？**BeautifulSoup（bs4）就是为这而生的第三方库**——它把 HTML 字符串解析成一棵"标签树"，之后想找什么标签、什么 class，一句话的事（真实环境需先安装：`pip install bs4`）：

```python
from bs4 import BeautifulSoup  # 需要先安装：pip install bs4

html = '<div class="channel"><a href="/news/1">情报一</a><a href="/news/2">情报二</a></div>'
soup = BeautifulSoup(html, "html.parser")   # 建"汤"：把 HTML 解析成标签树
for a in soup.find_all("a"):                 # 找所有 <a> 标签
    print(a.text, "→", a.get("href"))
# 情报一 → /news/1
# 情报二 → /news/2
```

- `find_all("a")`：返回所有 `<a>` 标签；`find("a")` 只返回第一个
- `a.text`：标签里的文字；`a.get("href")`：取 href 属性的值
- 按 class 定位：`soup.select(".channel")`，或 `find_all("div", class_="channel")`

> ⚠️ 新手最容易踩的坑：
> 1. bs4 是**第三方库**，必须先 `pip install bs4` 才能 import；没装就 `from bs4 import BeautifulSoup` 会报 `ModuleNotFoundError`
> 2. `class` 是 Python 关键字，bs4 里按 class 找要用 **`class_`（带下划线）**，写成 `class=` 直接语法错误
> 3. **本课的判题环境（Pyodide）没有预装 bs4**——所以本课练习我们用"正则"这把轻量武器，直接从 HTML 字符串里提取数据

## 🧬 用正则提取链接（判题环境方案）

bs4 在真实环境很香，但本课判题环境没有它。换个思路：**HTML 本质就是字符串，链接都藏在 `<a href="...">` 这个固定模板里**——用正则的 `re.findall` 就能把 href 的值一把全抠出来：

```python
import re

html = '<a href="/news/1">情报一</a><a href="/news/2">情报二</a>'
links = re.findall(r'<a href="(.*?)">', html)
for link in links:
    print(link)
# /news/1
# /news/2
```

- `re.findall(模式, 文本)`：返回**所有**匹配的列表
- `(.*?)` 是**非贪婪**匹配：只吃最短的一段，碰到下一个 `">` 就停
- 没有匹配时 `findall` 返回空列表，`for` 循环什么都不打印——不会报错

> ⚠️ 新手最容易踩的坑：
> 1. 忘写问号 `?`：`(.*)` 贪婪匹配会**从第一个 href 一路吃到最后一个引号**，把中间多个链接全吞成一个，打印出来全乱了
> 2. 括号 `( )` 要放在**href 值的位置**：`r'<a href="(.*?)">'` 里 `(.*?)` 才是被提取的部分
> 3. 模式里的引号、尖括号要和 HTML 源码**一字不差**，多一个空格都匹配不上
