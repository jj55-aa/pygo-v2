# 前端骨架——看懂 AI 写的前端

## 🏗️ 前端三件套：门面是怎么立起来的

建造工地开工，包工头要干的第一件事就是立「门面」——**用户能看到、能点到的整个页面，就是门面，也就是前端**。这扇门面不是一个人搭的，而是**前端三件套**三个工种各管一摊：

| 三件套 | 管什么 | 工地比喻 |
| --- | --- | --- |
| **HTML** | 结构：页面骨架（标题、按钮、图片放哪） | 承重墙和隔断 |
| **CSS** | 样式：颜色、字号、间距、圆角（好不好看） | 粉刷和装修 |
| **JS** | 交互：点击弹窗、跳转、发请求（动不动得了） | 电梯和自动门 |

三样缺一不可：没有 HTML 就没有「墙」，没有 CSS 就是毛坯房，没有 JS 门面就一潭死水。

怎么「看懂」一段前端？判题环境里没有真浏览器，我们用 **Python 字符串模拟**：把 HTML 当成一段文本，用 `in` 检查里面有没有某个标签：

```python
html = "<h1>工地大门</h1><button>开工</button>"
print("有标题:", "<h1>" in html)
print("有按钮:", "<button>" in html)
```

> ⚠️ 新手最容易踩的坑：
> 1. 三件套不是「三选一」——一个正经页面通常三样都要：HTML 管结构、CSS 管样式、JS 管交互。
> 2. 别把「样式」记到 HTML 头上：`<h1>` 只负责声明「这是个标题」，字多大、什么颜色是 CSS 的活。

## 🧱 HTML 骨架：先看懂标签结构

HTML = 搭页面的「标签积木」。AI 写的前端无论多花哨，骨架永远是这套结构：

```python
page = """<html>
<body>
  <h1>工地大门</h1>
  <div>
    <button>开工</button>
    <a href="plan.html">查看计划</a>
    <img src="crane.png">
  </div>
</body>
</html>"""
print("含 html 骨架:", "<html>" in page)
print("含 body 内容区:", "<body>" in page)
print("含 div 盒子:", "<div>" in page)
```

怎么读骨架：
- `<html>` 包住整个页面，`<body>` 包住「用户能看到的内容」
- `<h1>`/`<h2>` 是标题，`<button>` 是按钮，`<a href="...">` 是链接，`<img src="...">` 是图片
- 多数标签**成对出现**：`<h1>文字</h1>`（开标签 + 闭标签，闭标签多一个 `/`）
- `<div>` 是「盒子」，用来把内容分组盛放——页面里到处是它

> ⚠️ 新手最容易踩的坑：
> 1. 找元素先认「标签名」，别认「文字」——`<h1>工地</h1>` 里的标签是 `h1`，不是「工地」两个字。
> 2. `<a>` 和 `<img>` 常带属性：`href` 指向跳转地址、`src` 指向图片地址——属性写在标签**内部**，所以判断链接要认 `<a`（不是 `<a>`），因为链接总是 `href="..."` 跟着。

## 🎨 CSS 与 ⚡ JS 分工：管好看 vs 管能动

有了 HTML 骨架，页面还只是「毛坯房」。剩下两个工种的活儿要分清楚：

- **CSS**（样式）：管「好不好看」——颜色、字号、间距、圆角、背景。写在 `<style>` 块里或 `.css` 文件里
- **JS**（交互）：管「动不动得了」——点击弹窗、表单校验、跳转页面、向后端发请求。写在 `<script>` 块里或 `.js` 文件里

判断口诀：**CSS 管好看，JS 管能动**。按钮变红是 CSS，按钮点了弹窗是 JS。

```python
html = "<style>h1{color:red;font-size:24px}</style><script>alert('开工！')</script>"
print("含样式块(管好看):", "<style>" in html)
print("含交互脚本(管能动):", "<script>" in html)
```

> ⚠️ 新手最容易踩的坑：
> 1. 「好看」和「能动」别混：一个管「长什么样」，一个管「做什么动作」，代码里长得也不一样（`<style>` vs `<script>`）。
> 2. `.css` 文件里不写交互逻辑，`.js` 文件里也别硬塞样式——分工清楚，AI 写的代码你才看得懂。

## 🤖 看懂 AI 给的前端：一个文件就能跑

AI 生成的前端骨架，最常见的形态是——**一个 HTML 文件**：`index.html` 里直接内嵌 `<style>` 和 `<script>`，浏览器双击打开就能跑，不用装任何东西。这就是「最小可运行」的前端骨架。

前端文件类型（认脸）：

| 文件后缀 | 管什么 | 常见名字 |
| --- | --- | --- |
| `.html` | 结构：页面骨架（可内嵌样式和脚本） | index.html |
| `.css` | 样式：颜色/字号/间距 | style.css |
| `.js` | 交互：点击/弹窗/发请求 | app.js |

从哪看起（3 步）：
1. **先找 `<body>`**——用户能看到的内容都在里面
2. **再数结构元素**：`<h1>/<h2>` 标题、`<button>` 按钮、`<a>` 链接、`<img>` 图片
3. **最后看配件**：`<style>` 管外观、`<script>` 管动作

```python
html = "<html><body><h1>工地</h1><button>开工</button></body></html>"
print("HTML 骨架:", "<html>" in html)
print("页面内容区:", "<body>" in html)
print("这就是一个能直接跑的页面骨架！")
```

> ⚠️ 新手最容易踩的坑：
> 1. 「一个 HTML 文件能跑」≠「整个网站只有一个文件」——真实项目常把 css/js 拆成单独文件，但看懂最小骨架，从一个文件开始最省力。
> 2. 别指望双击 `.css` 文件看到页面——浏览器认的是 HTML，css/js 是给 HTML 当「配件」的，只有 `.html` 才是「门面」本身。
