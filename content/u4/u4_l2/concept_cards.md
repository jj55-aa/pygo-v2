# 函数的应用——默认参数、关键字参数和作用域

## 🔧 默认参数：不点单也有标配

上节课的函数，参数都得「现点现给」。但有些参数**大多数时候都是一个值**——比如奶茶店默认加糖 2 份，只有特殊要求才改。Python 允许在定义函数时给参数**设置默认值**：

```python
def make_juice(fruit, sugar=2):
    return fruit + "汁，加糖" + str(sugar) + "份"

print(make_juice("橙子"))           # 橙子汁，加糖2份（用默认值）
print(make_juice("柠檬", sugar=5))  # 柠檬汁，加糖5份（自己指定）
```

规则很简单：**不传**这个参数 → 用默认值；**传了** → 用你传的值，默认值被覆盖。

> ⚠️ 位置有讲究：**带默认值的参数必须放在不带默认值的参数后面**。写成 `def f(a=1, b):` 直接报 `SyntaxError`——就像点单，「必选项」得排前面，默认项排后面。

> ⚠️ 经典大坑：**默认值别用可变对象（比如列表 `[]`）**。默认值只在定义函数时创建一次，之后每次调用都共用同一个，会「记住」上一次的内容。正确写法：默认值用 `None`，在函数里再创建。

## 🏷️ 关键字参数：点单时喊名字

按位置传参有个小烦恼：参数一多，就记不清顺序了。**关键字参数**就是解法——调用时直接写 **`参数名=值`**，顺序就无所谓了，因为 Python 是**按名字**找参数的，不是按位置。

```python
def order(size, sugar, ice):
    return size + "，" + str(sugar) + "分糖，" + ice

print(order(size="大杯", ice="去冰", sugar=3))
# 大杯，3分糖，去冰

def add(a, b, c):
    return a + b + c

print(add(1, 2, c=3))    # 6，前两个按位置，最后一个按名字
```

也可以**混着用**：位置参数在前，关键字参数在后。

> ⚠️ 混用时顺序有硬性规定：**位置参数必须在关键字参数前面**。写 `add(a=1, 2, 3)` 会直接报语法错误。

## 🌍 变量作用域：调料只能在这个锅里用

函数里的变量就像**炒菜时用的调料**——这份菜谱的调料，做别的菜用不上。Python 里：

- **全局变量**：在函数**外面**（模块顶层）定义的变量，整个文件里都能用
- **局部变量**：在函数**里面**定义的变量，**只有这个函数能用**，函数一结束就「消失」了

```python
x = 100          # 全局变量

def change():
    x = 10       # 局部变量！跟外面的 x 没关系
    print(x)     # 10

change()         # 打印 10
print(x)         # 100，外面的 x 一点没变
```

函数里的 `x = 10` 是**新建**了一个局部变量，和外面那个全局 `x` 只是**恰好同名**，互不相干。

> ⚠️ 最典型的报错：在函数外面想用函数里的变量——`def calc():` 里的 `num` 是局部变量，函数一结束就被回收了，外面 `print(num)` 会报 `NameError: name 'num' is not defined`。那函数里的数据怎么拿出来？**用 `return`**！返回值就是最正规的「递菜」通道。

## 🔄 global：把调料端出锅

万一真的想在函数里**修改**全局变量呢？用 `global` 关键字声明一下：

```python
count = 0          # 全局变量：金币数

def earn_gold():
    global count   # 声明：我要用外面那个 count
    count += 10

earn_gold()
earn_gold()
print(count)       # 20
```

没有 `global` 的话，`count += 10` 会被当成「新建局部变量」，而且因为没初始化还会报错（`UnboundLocalError`）。

> ⚠️ 但**强烈建议少用 `global`**！函数偷偷改全局变量，代码一长就「牵一发动全身」，很难排查 bug。更好的习惯是：**用参数传进去，用返回值传出来**，比如 `count = earn_gold(count)`——清清楚楚，函数不偷偷改外面的世界。
