# 函数与模块——把代码打包成"预制菜"

## 🍱 函数就是"预制菜"

你有没有遇到过这种情况：登录要验证密码、付款要验证密码、查加密文件还要验证密码——**同一段「验证密码」的代码要写三遍**！又长又啰嗦，万一规则改了（密码长度从 6 位改成 8 位），你得改三个地方，漏改一处就出 bug。

Python 的解决办法就是**函数**：把一段代码**打包**起来，像预制菜一样——做好一份，想用的时候热一热就能端上桌。

其实你早就在用函数了！`print()`、`input()`、`type()`、`len()`……都是 Python 提前帮你打包好的「预制菜」，我们叫它**内置函数**。这节课我们学的是：**自己当厨师，做自己的预制菜**。

```python
def say_hello():
    print("你好，世界！")

say_hello()    # 调用第一次
say_hello()    # 调用第二次
```

输出两遍「你好，世界！」——**做一次，吃无数次**，这就是函数最大的好处。

## ✍️ 定义函数：把菜谱写下来

用 `def` 关键字定义函数，格式是 `def 函数名(参数):` + 缩进的函数体。注意三件事：

- `def` 后面的**函数名**，命名规则和变量一样（字母数字下划线、数字不能开头、见名知意）
- 函数名后面**必须有一对圆括号**，哪怕没有参数
- 括号后面有个**英文冒号 `:`**，函数体要**缩进**——和 `if`、`for` 一个套路

> ⚠️ 三个新手常踩的坑：
> 1. 忘记写冒号 `:` → 报 `SyntaxError`
> 2. 函数体忘了缩进 → 报 `IndentationError`
> 3. 把函数名写成 Python 关键字（比如 `def if():`）→ 直接报错

**定义完函数，代码并不会执行。** 函数体是「懒」的，只有被**调用**的时候才干活。函数里的三引号 `"""..."""` 叫 docstring，是写给未来的自己看的说明文字。

```python
def say_hello():
    """打印一句问候语"""
    print("你好，世界！")

print("函数已经定义好啦")
say_hello()    # 这句才会真的执行函数体
```

看输出顺序：先是「函数已经定义好啦」，然后才轮到「你好，世界！」——因为定义函数本身不干活，只有最后那行 `say_hello()` 才真正调用了它。

## 📞 调用与参数：把菜端上桌、给菜加料

调用函数很简单：**函数名 + 圆括号**。只写函数名、不加括号，是**不调用**的——Python 只会「提到」这个函数，不会执行它，就像你念了一遍菜名，厨师不会上菜。想用几遍就调用几遍。

光会打招呼还不够。要是函数能根据「给它的数据」干不同的活，那就厉害了——这就是**参数**。`name` 是函数里的**形参**（占位符），调用时写进括号里的 `"小明"` 叫**实参**（真实的数据）。**实参会按位置「对号入座」填进参数里。** 多个参数用逗号分隔。

```python
def say_hello():
    print("你好，世界！")

say_hello()      # 调用一次
say_hello()      # 再调用一次

def greet(name):
    print("你好，" + name + "！")

greet("小明")    # 你好，小明！
greet("小红")    # 你好，小红！
```

参数让同一个函数能处理**不同**的数据——函数是模具，参数是往里倒的原料。

> ⚠️ 传参个数必须和定义时一致。定义了两个参数，调用时只传一个，会报错：
> `TypeError: add() missing 1 required positional argument: 'b'`

## 📤 返回值：函数把结果递出来

上面的函数只是把结果**打印**出来。可如果我想**把结果存起来接着用**呢？这就要靠 `return`（返回）：把结果**递**给调用者。

```python
def add(a, b):
    return a + b

result = add(1, 2)
print(result)        # 3
print(result * 10)   # 30，返回值还能继续参与运算！
```

> ⚠️ **`print` 和 `return` 是两回事**：`print` 只是把东西「亮」在屏幕上，看完就没了；`return` 是把结果「递」给调用者，能存进变量继续用。**想让函数产出数据，必须用 `return`。**

关于 `return` 还有两个小知识：`return` 后面可以跟表达式，Python 会先算出结果再返回；`return` 一旦执行，**函数立刻结束**，后面的代码不跑了。如果函数**没有** `return`，Python 会默认返回 `None`（表示「什么都没有」）。

## 📦 模块：把别人的"预制菜"搬回家

自己做饭累，那就**买现成的**。Python 自带一个巨大的「预制菜仓库」，叫**标准库**，里面分门别类放好了各种模块（module），每个模块里都是别人写好的函数。用 `import` 把它们请进来，用法是 `模块名.函数名()`——点号的意思是「到 math 这个仓库里，拿 sqrt 这个函数」。

```python
import math
import random as r

print(math.sqrt(9))       # 3.0 开平方
print(r.randint(1, 6))    # 1~6 的随机整数，掷骰子
```

`import` 还有两种常用写法：`from math import sqrt`（直接导入函数，用的时候不用写模块名）和 `import random as r`（起别名，名字短更好写）。

> ⚠️ 两个坑：
> 1. `from 模块 import 函数` 导入的同名函数会**互相覆盖**——后导入的赢。多人协作时更推荐 `import 模块名` 的写法，用 `模块名.函数名` 区分，永远不会撞车。
> 2. 忘了 `import` 就直接用 `math.sqrt`，会报 `NameError: name 'math' is not defined`。
