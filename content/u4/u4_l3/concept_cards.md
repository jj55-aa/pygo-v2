# 函数使用进阶——把工具用得飞起

## 🏃 lambda：一句话写个函数

有些函数**特别简单**，简单到专门写一个 `def` 有点小题大做。比如「把一个数翻倍」——用 **lambda** 一句话就能搞定：

```python
# lambda 写法：一句话
double = lambda x: x * 2
print(double(4))     # 8
print(double(10))    # 20

# 普通 def 写法：完全等价，只是更长
def double_def(x):
    return x * 2
print(double_def(10))   # 20
```

`lambda` 的格式：`lambda 参数: 返回值表达式`。冒号左边是参数（多个用逗号分隔），冒号右边**只能写一个表达式**，表达式的值就是返回值。它没有名字，所以叫**匿名函数**——不过你可以把它存进变量再调用。

> ⚠️ **lambda 只能写一个表达式**！不能写 `if` 语句、不能写多行代码。逻辑一复杂，还是老老实实用 `def`。

lambda 最大的舞台不是单打独斗，而是配合**高阶函数**一起出场——你马上就会看到。

## 🪆 递归：函数自己调用自己

**递归**听起来很高级，其实就一句话：**函数在函数体里调用自己**。

想象一套**套娃盒子**：大盒子套中盒子，中盒子套小盒子。要拿到最里面的东西，就得一层层打开——这叫「递」；拿到之后再一层层装回去——这叫「归」。递归就是这么一个「拆了又装」的过程。

看最经典的例子——求阶乘（5! = 5 × 4 × 3 × 2 × 1）：

```python
def fac(n):
    if n <= 1:
        return 1                 # 出口：最小的盒子，不用再拆了
    return n * fac(n - 1)        # 递归：拆一层，剩下的交给"小一号的自己"

print(fac(5))    # 120
```

`fac(5)` 的执行过程就像拆套娃：先一路拆下去 `5 * fac(4)` → `5 * (4 * fac(3))` → …… 一直拆到 `fac(1)` 返回 1，再一层层装回去：5 × 4 × 3 × 2 × 1 = 120。

注意那个 `if n <= 1: return 1`——这是递归的**出口（基线条件）**。没有它，函数会无限调用自己，直到把内存耗尽：

> ⚠️ **忘了写出口，就是无限递归**。Python 会报 `RecursionError: maximum recursion depth exceeded`（超出最大递归深度）。写递归第一件事：**先想清楚出口在哪**。

递归的精髓是**把大事化小**：解决一个大问题，先解决比它小一号的同类问题，直到小到不用再拆。

## 🎩 高阶函数：经理不干活，只安排人

普通函数是**干活的人**：厨师负责做菜，服务员负责上菜。而**高阶函数**是**经理**——自己不直接干活，而是**安排函数去干活**。

怎么安排？把函数**当作参数**传给另一个函数：

```python
def apply_func(func, x):
    """调用传入的函数 func，把 x 交给它处理"""
    return func(x)

# 传一个"加 10"的函数进去
print(apply_func(lambda x: x + 10, 5))    # 15
# 传一个"平方"的函数进去
print(apply_func(lambda x: x * x, 4))     # 16
```

看出来了吗：`apply_func` 自己不会加、不会乘，它只负责「调用传进来的函数」。**换一个函数参数，就换了一种行为**——这就是经理的灵活之处。

> 💡 判断高阶函数很简单：**参数里有函数，或者返回值是函数**，就是高阶函数。`lambda` 经常和高阶函数组队，因为它「即写即用」，不用专门定义。

## ⚙️ map 和 filter：批量加工流水线

Python 内置了两个超实用的高阶函数，专门用来**批量处理列表**。

- **`map(函数, 列表)`**：把列表里每个元素都过一遍函数，返回加工后的结果
- **`filter(函数, 列表)`**：用函数当「筛子」，只留下让函数返回 `True` 的元素

```python
nums = [1, 2, 3, 4, 5]

# 每个数都平方（用 map）
squares = list(map(lambda x: x * x, nums))
print(squares)    # [1, 4, 9, 16, 25]

# 留下奇数（用 filter）
odds = list(filter(lambda x: x % 2 == 1, nums))
print(odds)       # [1, 3, 5]

# 对比：不用 map 的写法（循环 + 空列表 + append，五六行）
squares2 = []
for x in nums:
    squares2.append(x * x)
print(squares2)   # [1, 4, 9, 16, 25]
```

> ⚠️ 最大的坑：`map` 和 `filter` 返回的不是列表，而是**可迭代对象**（一个「懒」的流水线）。直接 `print` 只会看到 `<map object at 0x...>`。**必须用 `list()` 转一下**（或者用 `for` 循环遍历）才能看到里面的数据。
